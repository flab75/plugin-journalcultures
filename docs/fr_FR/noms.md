# Noms des plantes

Pourquoi le romarin est-il la « rosée de la mer », et l'officinalis une plante d'apothicaire ? Ce dictionnaire raconte d'où viennent les noms botaniques : un genre (le premier mot, avec majuscule) puis une épithète (le second, en minuscules), presque toujours du latin ou du grec, parfois un hommage à un botaniste.

Dans le plugin (onglet « Noms des plantes » de la notice), tape un mot dans la case de recherche : genre, épithète, nom français ou ancien nom. La recherche ignore les accents et les majuscules. La fiche de chaque plante montre aussi, à la ligne « Origine du nom », les mots de son nom botanique qui figurent ici.

## Les noms qui ont changé

Les botanistes renomment les plantes quand on comprend mieux leur parenté (aujourd'hui surtout grâce à l'ADN) ou quand on retrouve un nom plus ancien, prioritaire selon le code de nomenclature. Le romarin, *Rosmarinus officinalis* en 1984, est aujourd'hui *Salvia rosmarinus* ; le *Poncirus* et le kumquat (*Fortunella*) sont rangés dans *Citrus* par certaines bases. L'ancien nom garde son entrée : elle donne son étymologie, puis le nom accepté aujourd'hui. Le nom retenu est celui de la base WCVP (Kew), lue par GBIF en novembre 2026 ; une base peut encore en préférer un autre.

## Dictionnaire

### A

- **Abies** (genre ; latin) : nom latin du sapin. L'origine du mot latin reste inconnue pour Ferrari ; Théis le croit celtique et Gentil le tire du grec a- + bios, « qui vit longtemps » : les trois sources ne s'accordent pas. *Sources : Ferrari 1984 p. 5 ; Théis 1810, s.v. Abies ; Gentil 1923 p. 1 ; Wiktionary, s.v. Abies.*
- **Acer** (genre ; latin) : « dur, pointu ». Les Romains appelaient ainsi l'érable, dont le bois dur servait à faire des lances. *Sources : Ferrari 1984 p. 5 ; Théis 1810, s.v. Acer ; Gentil 1923 p. 1.*
- **Aceras** (genre ; grec) : « sans corne ». Du a privatif et de keras (la corne) : la fleur n'a pas d'éperon, détail rare chez ces orchidées. Ancien nom (Ferrari 1984) : Aceras → nom actuel : Orchis (GBIF/WCVP 2026), l'homme-pendu est Orchis anthropophora. *Sources : Ferrari 1984 p. 5 ; Gentil 1923 p. 1.*
- **Achillea** (genre ; grec) : plante d'Achille. Selon la légende, le héros aurait soigné les blessures de ses soldats avec l'achillée, d'où son usage ancien contre les coupures. *Sources : Ferrari 1984 p. 5 ; Théis 1810, s.v. Achillea ; Gentil 1923 p. 2.*
- **acris** (épithète ; latin) : âcre, piquant au goût. Acris (acris, acre) est une forme ancienne de l'adjectif acer, que Linné a choisie, par exemple pour la renoncule âcre, Ranunculus acris, au goût brûlant. Le même mot acer a aussi donné le nom latin de l'érable, peut-être à cause des pointes de ses feuilles ; **une seule source** (Wiktionary). *Sources : Ferrari 1984 p. 129 ; Gentil 1923 p. 178 ; Wiktionary, s.v. acer.*
- **Adenoscilla** (genre ; grec) : « scille à glandes ». De adên (la glande) accolé au nom de la scille ; Ferrari rattache ce second élément à un verbe grec qui veut dire nuire, à cause de la toxicité de la plante. Ancien nom (Ferrari 1984) : Adenoscilla → nom actuel : Scilla (GBIF/WCVP 2026). **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 6.*
- **Aesculus** (genre ; latin) : ancien nom latin d'un chêne à glands comestibles, rapproché de esca, « nourriture ». Linné l'a repris pour le marronnier d'Inde, dont les marrons ne se mangent pas. *Sources : Ferrari 1984 p. 7 ; Théis 1810, s.v. Esculus.*
- **Agropyron** (genre ; grec) : « blé des champs ». De agros ou agrios (le champ, sauvage) et de pyros (le blé) : une herbe des champs qui rappelle le blé. Ancienne graphie chez Ferrari : Agropyrum. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 8.*
- **albus** (épithète ; latin) : blanc. On le trouve sous les formes alba et album ; le mûrier blanc, Morus alba, doit son nom à ses fruits blancs. Au sens propre, albus désigne plutôt un blanc mat ; **une seule source** (Wiktionary). *Sources : Ferrari 1984 p. 131 ; Gentil 1923 p. 140 ; Wiktionary, s.v. albus.*
- **Alchemilla** (genre ; arabe par le latin médiéval) : « petite alchimie ». Les alchimistes recueillaient la rosée perlée sur ses feuilles pour leurs préparations, jusqu'à la pierre philosophale. Ancienne graphie chez Ferrari : Alchimilla. *Sources : Ferrari 1984 p. 9 ; Gentil 1923 p. 6.*
- **Aldrovanda** (genre ; nom de personne) : « plante d'Aldrovandi ». Dédiée au naturaliste italien Ulisse Aldrovandi (1522-1605). Ancienne graphie chez Ferrari : Aldrovandia. *Sources : Ferrari 1984 p. 9 ; Burkhardt 2018, s.v. Aldrovanda.*
- **Allium** (genre ; latin) : nom latin de l'ail. Théis le rapproche d'un mot celtique all, « brûlant », à cause de son goût (à notre avis, piste ancienne fragile). *Sources : Ferrari 1984 p. 10 ; Théis 1810, s.v. Allium ; Gentil 1923 p. 7.*
- **Alnus** (genre ; latin) : nom latin de l'aulne. Théis y voit un mot celtique lié au bord des rivières, où pousse l'arbre (à notre avis, piste ancienne fragile). *Sources : Ferrari 1984 p. 10 ; Théis 1810, s.v. Betula ; Gentil 1923 p. 9.*
- **Aloysia** (genre ; latin moderne) : dédié à Marie-Louise de Bourbon-Parme (Aloysia en latin), épouse de Charles IV d'Espagne. C'est le genre de la verveine citronnelle. Ancien nom (Ferrari 1984) : Lippia citriodora → nom actuel : Aloysia citrodora (GBIF/WCVP 2026) ; Lippia honore Augustin Lippi, médecin et naturaliste mort en Abyssinie en 1705. *Sources : Wiktionary, s.v. Aloysia ; Burkhardt 2018, s.v. Aloysia ; Ferrari 1984 p. 77 (Lippia) ; Gentil 1923 p. 126 (Lippia).*
- **alpinus** (épithète ; latin) : des Alpes, alpin. Formé sur Alpes, le nom latin des Alpes ; formes alpina, alpinum, comme pour l'aster des Alpes, Aster alpinus. *Sources : Ferrari 1984 p. 131 ; Gentil 1923 p. 25 ; Wiktionary, s.v. Alpinus.*
- **Althaea** (genre ; grec) : de althein, « guérir », pour les vertus adoucissantes de la guimauve. La rose trémière, longtemps nommée Althaea rosea, s'appelle aujourd'hui Alcea rosea (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 10 ; Gentil 1923 p. 10.*
- **Alyssoides** (genre ; grec) : « qui ressemble à Alyssum ». Le suffixe -oides marque la ressemblance avec l'alysson, dont le genre est proche. Nom actuel (GBIF/WCVP 2026) de l'ancien Vesicaria de Ferrari : la vésicaire est Alyssoides utriculata. *Sources : Ferrari 1984 p. 10 ; Gentil 1923 p. 98 (épithète alyssoides).*
- **Amaracus** (genre ; grec) : nom antique d'une plante aromatique, rapproché du dictame et de la marjolaine. Ancien nom (Ferrari 1984) : Amaracus → nom actuel : Origanum (GBIF/WCVP 2026), le dictame de Crète est Origanum dictamnus. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 11.*
- **amarus** (épithète ; latin) : amer. Formes amara et amarum ; Gentil l'emploie pour des plantes à saveur amère. Le mot remonte à une racine qui voulait dire à la fois amer et cru, comme le grec ômos, cru ; **une seule source** (Wiktionary). *Sources : Ferrari 1984 p. 131 ; Gentil 1923 p. 41 ; Wiktionary, s.v. amarus.*
- **amblycarpa** (épithète ; grec) : à fruit émoussé. Composé de amblys (émoussé, obtus) et de karpos (fruit) (à notre avis), sans doute pour un fruit arrondi sans pointe. **une seule source** (pour karpos). Nom actuel : Citrus ×amblycarpa (Hassk.) Ochse (GBIF/WCVP 2026), accepté dans les deux bases. *Sources : Ferrari 1984 p. 164, s.v. Microcarpus ; GBIF/WCVP 2026.*
- **Ambrosina** (genre ; nom de personne) : « plante d'Ambrosini ». Dédiée au botaniste italien Bartolomeo Ambrosini (1588-1657). Ancienne graphie chez Ferrari : Ambrosinia. *Sources : Ferrari 1984 p. 11 ; Burkhardt 2018, s.v. Ambrosina.*
- **Ammophila** (genre ; grec) : « amie du sable ». De ammos (le sable) et de philos (ami) : c'est le grand roseau des dunes, qui tient le sable. Ancien nom (Ferrari 1984) : Ammophila → nom actuel : Calamagrostis (GBIF/WCVP 2026), l'oyat est Calamagrostis arenaria. *Sources : Ferrari 1984 p. 11 ; Gentil 1923 p. 12.*
- **Anagallis** (genre ; grec) : le mouron chez les Grecs. Gentil avance, avec prudence, un verbe grec qui veut dire « rire », pour des vertus réjouissantes qu'on prêtait à la plante ; **une seule source** (Gentil, pour cette piste). Ancien nom (Ferrari 1984) : Anagallis → nom actuel : Lysimachia (GBIF/WCVP 2026), le mouron rouge est Lysimachia arvensis. *Sources : Ferrari 1984 p. 12 ; Gentil 1923 p. 12.*
- **Androsace** (genre ; grec) : « bouclier d'homme ». De anêr, andros (l'homme) et d'un mot grec pour le bouclier, à cause de la forme du feuillage. Nom actuel (GBIF/WCVP 2026) de l'ancien Gregoria. *Sources : Ferrari 1984 p. 13 ; Gentil 1923 p. 13.*
- **Anemone** (genre ; grec) : rattaché à anemos, « le vent ». On disait que la fleur ne s'ouvrait qu'au souffle du vent ; certains auteurs y voient plutôt un emprunt sémitique (à notre avis, la piste du vent reste la plus citée). *Sources : Ferrari 1984 p. 14 ; Théis 1810, s.v. Anemone ; Gentil 1923 p. 14.*
- **Anethum** (genre ; grec) : nom grec et latin de l'aneth (anêthon). Le fenouil, lui, a d'abord été classé dans ce genre. *Sources : Ferrari 1984 p. 14 ; Théis 1810, s.v. Anethum ; Gentil 1923 p. 14.*
- **Angelica** (genre ; latin médiéval) : « herbe angélique ». Le nom vient des grandes vertus médicinales qu'on lui prêtait, comme un remède envoyé par les anges. *Sources : Ferrari 1984 p. 14 ; Théis 1810, s.v. Angelica ; Gentil 1923 p. 14.*
- **angustifolius** (épithète ; latin) : à feuilles étroites. Assemblage de angustus (étroit) et folium (feuille) ; formes angustifolia et angustifolium. *Sources : Ferrari 1984 p. 132 ; Gentil 1923 p. 98 ; Wiktionary, s.v. angustifolius.*
- **annuus** (épithète ; latin) : annuel, qui vit une seule année. Tiré de annus, l'année ; formes annua et annuum. Il s'oppose à biennis (deux ans) et perennis (plusieurs années). *Sources : Ferrari 1984 p. 132 ; Gentil 1923 p. 31 ; Wiktionary, s.v. annuus.*
- **Anthyllis** (genre ; grec) : nom grec d'une plante. Ferrari y voit anthyllion, une plante du littoral mal identifiée ; Gentil le tire de anthos (fleur) et ioulos (duvet), pour le calice velu. Nom actuel (GBIF/WCVP 2026) de l'ancien Hymenocarpus. *Sources : Ferrari 1984 p. 15 ; Gentil 1923 p. 16.*
- **Antirrhinum** (genre ; grec) : « comme un nez » (anti + rhis, rhinos). La fleur du muflier rappelle un museau, qui s'ouvre quand on la pince. *Sources : Ferrari 1984 p. 15 ; Théis 1810, s.v. Antirrhinum ; Gentil 1923 p. 16.*
- **Apium** (genre ; latin) : nom latin du céleri et de plantes voisines. Théis le tire d'un mot celtique apon, « eau », car l'ache sauvage aime les lieux humides (à notre avis, piste ancienne fragile). *Sources : Ferrari 1984 p. 15 ; Théis 1810, s.v. Apium ; Gentil 1923 p. 17.*
- **aquaticus** (épithète ; latin) : qui vit dans l'eau ou au bord de l'eau. Formé sur aqua, l'eau ; formes aquatica et aquaticum, comme la menthe aquatique, Mentha aquatica. *Sources : Ferrari 1984 p. 133 ; Gentil 1923 p. 136 ; Wiktionary, s.v. aquaticus.*
- **Aquilegia** (genre ; latin) : deux explications. Pour Ferrari et Gentil, de aquilegium, « réservoir d'eau », pour les éperons de la fleur ; pour Théis (et Gentil en second), de aquila, « aigle », dont les éperons rappelleraient les serres. *Sources : Ferrari 1984 p. 15 ; Théis 1810, s.v. Aquilegia ; Gentil 1923 p. 17.*
- **arborescens** (épithète ; latin) : qui prend l'allure d'un arbre. C'est le participe du verbe arborescere, devenir arbre ; la forme est la même au masculin et au féminin, arborescens. *Sources : Ferrari 1984 p. 133 ; Gentil 1923 p. 21 ; Wiktionary, s.v. arborescens.*
- **Arbutus** (genre ; latin) : nom latin de l'arbousier, peut-être d'origine celtique, « buisson âpre » (à notre avis, piste ancienne fragile). L'épithète unedo viendrait de « unum edo », « j'en mange un seul », d'après Pline : le fruit est fade. *Sources : Ferrari 1984 p. 16 ; Théis 1810, s.v. Arbutus ; Gentil 1923 p. 18.*
- **Arenaria** (genre ; latin) : « des sables ». De arena (le sable) : la plupart de ces sablines poussent en terrain sablonneux. Nom actuel (GBIF/WCVP 2026) de l'ancien Gouffeia. *Sources : Ferrari 1984 p. 16 ; Gentil 1923 p. 19 ; Théis 1810, s.v. Arenaria.*
- **Armeniaca** (genre ; latin) : « d'Arménie ». L'abricotier passait pour venir d'Arménie ; il est arrivé en France au Moyen Âge. Ancien nom (Ferrari 1984) : Armeniaca → nom actuel : Prunus (GBIF/WCVP 2026), l'abricotier est Prunus armeniaca. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 17.*
- **aromaticus** (épithète ; latin, du grec) : aromatique, qui sent bon. Le latin l'a emprunté au grec arômatikos, de arôma, parfum, épice ; formes aromatica et aromaticum. *Sources : Ferrari 1984 p. 134 ; Wiktionary, s.v. aromaticus ; Wiktionnaire, s.v. aromaticus.*
- **Artemisia** (genre ; grec) : plante d'Artémis, déesse qui veillait sur les femmes, car on l'employait pour les troubles féminins. Certains la rattachent plutôt à la reine Artémise de Carie. *Sources : Ferrari 1984 p. 18 ; Théis 1810, s.v. Artemisia ; Gentil 1923 p. 21.*
- **Arthrocnemum** (genre ; grec) : « jambe articulée ». De arthron (l'articulation) et de knêmê (la jambe) : les tiges charnues semblent faites d'articles emboîtés. Ancien nom (Ferrari 1984) : Arthrocnemum → nom actuel : Salicornia (GBIF/WCVP 2026). **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 18.*
- **arvensis** (épithète ; latin) : des champs cultivés. Formé sur arvum, le champ labouré, avec le suffixe -ensis (qui habite) ; même forme au féminin, comme la renoncule des champs, Ranunculus arvensis. *Sources : Ferrari 1984 p. 134 ; Gentil 1923 p. 178 ; Wiktionary, s.v. arvensis.*
- **Asparagus** (genre ; grec) : nom grec de l'asperge (asparagos), qu'on rattache à l'idée de jeune pousse. *Sources : Ferrari 1984 p. 19 ; Gentil 1923 p. 23.*
- **Aspidium** (genre ; grec) : « petit bouclier ». De aspidion : l'indusie, petite membrane ronde qui couvre les spores, ressemble à un bouclier. Ancien nom (Ferrari 1984) : Aspidium → nom actuel : Tectaria (GBIF/WCVP 2026) pour le type du genre ; les espèces de France sont rangées aujourd'hui surtout dans Polystichum et Dryopteris (à notre avis, d'après les noms d'espèces). *Sources : Ferrari 1984 p. 19 ; Gentil 1923 p. 24.*
- **Asplenium** (genre ; grec) : « sans rate ». Du a privatif et de splên (la rate) : on prêtait à ces fougères le pouvoir de soigner les maux de rate. Nom actuel (GBIF/WCVP 2026) de l'ancien Scolopendrium : la scolopendre est Asplenium scolopendrium. *Sources : Ferrari 1984 p. 19 ; Gentil 1923 p. 24.*
- **Aster** (genre ; grec) : « étoile », pour la forme du capitule. Les asters d'automne d'Amérique du Nord (ex. Aster novi-belgii) sont passés dans Symphyotrichum ; Aster amellus reste un Aster (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 20 ; Théis 1810, s.v. Aster ; Gentil 1923 p. 25.*
- **Astrocarpus** (genre ; grec) : « fruit en étoile ». De astêr (l'étoile) et de karpos (le fruit) : les carpelles s'étalent en étoile. Ancien nom (Ferrari 1984) : Astrocarpus → nom actuel : Sesamoides (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 20 ; Gentil 1923 p. 27.*
- **Atriplex** (genre ; latin) : nom latin de l'arroche, d'origine incertaine. On le rapproche parfois d'un mot grec ancien pour la même plante, sans certitude. *Sources : Ferrari 1984 p. 21 ; Théis 1810, s.v. Atriplex ; Gentil 1923 p. 28.*
- **Aubrieta** (genre ; nom de personne) : « plante d'Aubriet ». Dédiée au peintre naturaliste français Claude Aubriet, mort en 1742. Ancienne graphie chez Ferrari : Aubrietia. *Sources : Ferrari 1984 p. 21 ; Burkhardt 2018, s.v. Aubrieta.*
- **aurantiifolia** (épithète ; latin) : à feuilles d'oranger. Formé de aurantium (oranger) et de folium (feuille) (à notre avis) : c'est la lime acide, dont le feuillage rappelle celui de l'oranger. Nom actuel : Citrus ×aurantiifolia (Christm.) Swingle (GBIF/WCVP 2026), accepté dans les deux bases. *Sources : Théis 1810, s.v. Citrus aurantium ; Ferrari 1984 p. 160, s.v. Latifolius ; GBIF/WCVP 2026.*
- **aurantium** (épithète ; latin médiéval) : l'oranger, l'orange. Théis le tire de aurum, l'or, pour la couleur du fruit ; le Wiktionnaire en fait un mot de latin médiéval tiré de l'arabe nāranj (persan nârang, sanskrit nāraṅga), la ressemblance avec aurum ayant seulement aidé : les deux sources ne sont pas d'accord sur l'origine première. Nom actuel : Citrus ×aurantium L. (GBIF/WCVP 2026), accepté ; le WCVP y range aussi l'orange douce, le pamplemousse et les mandarines sous forme de « formes » (f. aurantium, f. deliciosa), GBIF sans ces formes. *Sources : Théis 1810, s.v. Citrus aurantium ; Wiktionnaire 2026, s.v. aurantium et orange ; GBIF/WCVP 2026.*
- **aureus** (épithète ; latin) : doré, couleur d'or. Tiré de aurum, l'or ; formes aurea et aureum, comme la potentille dorée, Potentilla aurea, aux fleurs d'un jaune vif. *Sources : Ferrari 1984 p. 135 ; Gentil 1923 p. 173 ; Wiktionary, s.v. aureus.*
- **australasica** (épithète ; latin moderne) : d'Australasie. Formé sur australis, du sud (à notre avis) : c'est le citron caviar, ou lime digitée, décrit par Mueller sous Citrus puis placé par Swingle en 1915 comme type de son genre Microcitrus. Ancien nom : Microcitrus australasica → nom actuel : Citrus australasica F.Muell. (GBIF/WCVP 2026) ; GBIF garde encore Microcitrus australasica et met le nom en Citrus en synonyme. *Sources : Ferrari 1984 p. 135, s.v. Australis ; Gentil 1923 p. 104 ; Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **australis** (épithète ; latin) : austral, du sud. Vient de auster, le vent du sud. Ici une lime sauvage d'Australie. Ancien nom : Microcitrus australis → nom actuel : Citrus australis (GBIF/WCVP 2026) ; GBIF garde Microcitrus australis comme nom accepté. *Sources : Ferrari 1984 p. 135 ; Gentil 1923 p. 104 ; Wiktionary 2026, s.v. australis ; GBIF/WCVP 2026.*

### B

- **Barbarea** (genre ; latin) : « herbe de sainte Barbe ». Plante vulnéraire consacrée à sainte Barbe, patronne de ceux qui risquent la blessure. Ancienne graphie chez Ferrari : Barbaraea. *Sources : Ferrari 1984 p. 22 ; Gentil 1923 p. 30.*
- **Bassia** (genre ; nom de personne) : « plante de Bassi ». Dédiée à Ferdinando Bassi (1710-1774), botaniste de Bologne ; Ferrari le dit polonais, Burkhardt italien. Nom actuel (GBIF/WCVP 2026) de l'ancien Kochia. *Sources : Ferrari 1984 p. 22 ; Burkhardt 2018, s.v. Bassia.*
- **Begonia** (genre ; latin moderne) : dédié par Plumier à Michel Bégon (1638-1710), intendant de la marine et protecteur des botanistes. *Sources : Théis 1810, s.v. Begonia ; Burkhardt 2018, s.v. Begonia ; Wiktionary, s.v. Begonia.*
- **Bellis** (genre ; latin) : de bellus, « joli ». C'est le nom de la pâquerette, petite fleur gracieuse des pelouses. *Sources : Ferrari 1984 p. 23 ; Théis 1810, s.v. Bellis ; Gentil 1923 p. 31.*
- **Berberis** (genre ; arabe) : latinisé d'un nom arabe de l'épine-vinette. *Sources : Ferrari 1984 p. 23 ; Théis 1810, s.v. Berberis ; Gentil 1923 p. 31.*
- **bergamia** (épithète ; italien) : la bergamote. Le mot vient de l'italien bergamotta, soit du turc beg armudi, « poire du seigneur », soit de Bergama (Pergame) ; le Wiktionary anglais propose aussi la ville de Bergame : les sources hésitent. Swingle et Reece la rangent parmi les formes de l'orange amère, d'origine inconnue : mutation ou hybride, la question reste ouverte. Ancien nom : Citrus bergamia Risso et Poit. → nom actuel : Citrus ×limon (GBIF/WCVP 2026), même rattachement chez GBIF (C. limon). *Sources : Wiktionnaire 2026, s.v. bergamote ; Wiktionary 2026, s.v. bergamot ; Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **Beta** (genre ; latin) : nom latin de la bette et de la betterave. Théis y voit un mot celtique bett, « rouge » (à notre avis, piste ancienne fragile). *Sources : Ferrari 1984 p. 23 ; Théis 1810, s.v. Beta ; Gentil 1923 p. 32.*
- **Betula** (genre ; latin) : nom latin du bouleau, rattaché à un mot celtique de même sens (à notre avis, piste ancienne fragile). *Sources : Ferrari 1984 p. 23 ; Théis 1810, s.v. Betula ; Gentil 1923 p. 32.*
- **biennis** (épithète ; latin) : bisannuel, qui vit deux ans. Assemblage de bi- (deux) et annus (année) ; même forme au féminin, biennis, neutre bienne. *Sources : Ferrari 1984 p. 136 ; Gentil 1923 p. 147 ; Wiktionary, s.v. biennis.*
- **Blackstonia** (genre ; nom de personne) : « plante de Blackstone ». Dédiée à l'apothicaire et botaniste anglais John Blackstone (1712-1753). Nom actuel (GBIF/WCVP 2026) de l'ancien Chlora. **une seule source** (Burkhardt). *Sources : Burkhardt 2018, s.v. Blackstonia.*
- **Borago** (genre ; latin médiéval) : origine discutée. Ferrari et Gentil le tirent d'un mot arabe, « père de la sueur », la bourrache faisant transpirer ; Théis (et Gentil en second) y voit cor ago, « je stimule le cœur ». *Sources : Ferrari 1984 p. 25 ; Théis 1810, s.v. Borrago ; Gentil 1923 p. 34.*
- **Borderea** (genre ; nom de personne) : « plante de Bordère ». Dédiée à Henri Bordère (1825-1889), botaniste des Pyrénées, où pousse l'unique espèce. - **Brassica** (genre ; latin) : nom latin du chou. Théis le rattache à un mot celtique bresic, « chou » (à notre avis, piste ancienne fragile). La roquette (Eruca) est traitée par Théis au même endroit. *Sources : Ferrari 1984 p. 25 ; Théis 1810, s.v. Brassica ; Gentil 1923 p. 34.*
- **Buddleja** (genre ; nom de personne) : « plante de Buddle ». Dédiée au botaniste anglais Adam Buddle, de la fin du XVIIe siècle. Ancienne graphie chez Ferrari : Buddleia. *Sources : Ferrari 1984 p. 26 ; Burkhardt 2018, s.v. Buddleja.*

### C

- **caeruleus** (épithète ; latin) : bleu, bleu du ciel. Le mot dérive de caelum, le ciel ; formes caerulea et caeruleum (on écrit aussi coeruleus), comme la cupidone, Catananche caerulea, aux fleurs bleues. *Sources : Ferrari 1984 p. 138 ; Gentil 1923 p. 49 ; Wiktionary, s.v. caeruleus.*
- **Calamagrostis** (genre ; grec) : « herbe-roseau ». De kalamos (le roseau) et de agrôstis (une herbe des Grecs) : une graminée qui a l'allure d'un petit roseau. Nom actuel (GBIF/WCVP 2026) de l'ancien Ammophila. *Sources : Ferrari 1984 p. 27 ; Gentil 1923 p. 38.*
- **Calamintha** (genre ; grec) : « menthe ». Le second élément est minthê (la menthe), précédé selon Ferrari de kalamos, une plante herbacée. Ancien nom (Ferrari 1984) : Calamintha → nom actuel : Clinopodium (GBIF/WCVP 2026). **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 28.*
- **Calendula** (genre ; latin) : de calendae, premier jour du mois. Pour Théis, le souci fleurit presque tous les mois ; Gentil le relie aux calendes de juin : la nuance diffère. *Sources : Ferrari 1984 p. 28 ; Théis 1810, s.v. Calendula ; Gentil 1923 p. 39.*
- **Calluna** (genre ; grec) : de kallunein, « balayer, nettoyer », car on faisait des balais avec la callune. *Sources : Ferrari 1984 p. 28 ; Gentil 1923 p. 39.*
- **Camellia** (genre ; latin moderne) : dédié par Linné à Georg Joseph Kamel (1661-1706), jésuite apothicaire aux Philippines. *Sources : Théis 1810, s.v. Camellia ; Burkhardt 2018, s.v. Camellia ; Wiktionary, s.v. Camellia.*
- **Campanula** (genre ; latin) : « petite cloche », diminutif de campana, pour la forme de la fleur. *Sources : Ferrari 1984 p. 29 ; Théis 1810, s.v. Campanula ; Gentil 1923 p. 39.*
- **campestris** (épithète ; latin) : des champs, de la campagne. Tiré de campus, la plaine, le champ ; le latin classique disait campester au masculin, les botanistes emploient surtout campestris (même forme au féminin, neutre campestre). *Sources : Ferrari 1984 p. 138 ; Gentil 1923 p. 5 ; Wiktionary, s.v. campester.*
- **capensis** (épithète ; latin moderne) : du Cap, en Afrique du Sud. Formé sur le nom du cap de Bonne-Espérance avec le suffixe -ensis (originaire de) ; même forme au féminin, neutre capense. **une seule source** (Wiktionary). *Sources : Wiktionary, s.v. capensis.*
- **Capsicum** (genre ; latin moderne) : origine discutée. Ferrari la dit inconnue ; Théis y voit le grec kaptô, « je mords », pour le piquant ; Wiktionary penche pour capsa, « boîte », pour la forme du fruit creux. *Sources : Ferrari 1984 p. 30 ; Théis 1810, s.v. Capsicum ; Wiktionary, s.v. Capsicum.*
- **Cardamine** (genre ; grec) : « cresson ». Du nom grec kardamon, le cresson alénois, dont ces plantes ont la saveur et les usages. Nom actuel (GBIF/WCVP 2026) de l'ancien Dentaria. *Sources : Ferrari 1984 p. 30 ; Gentil 1923 p. 41.*
- **Carex** (genre ; latin) : nom latin des laîches. Les Romains appelaient ainsi des herbes aux feuilles coupantes ; Virgile emploie déjà le mot. Nom actuel (GBIF/WCVP 2026) de l'ancien Cobresia. *Sources : Ferrari 1984 p. 30 ; Gentil 1923 p. 43.*
- **Carpinus** (genre ; latin) : nom latin du charme. Théis le rattache à des mots celtiques, « bois » et « tête », pour son usage dans les jougs de bœufs (à notre avis, piste ancienne fragile). *Sources : Ferrari 1984 p. 30 ; Théis 1810, s.v. Carpinus ; Gentil 1923 p. 48.*
- **Castanea** (genre ; latin) : nom latin du châtaignier, emprunté au grec. Gentil le relie à la ville de Kastana en Thessalie ; **une seule source** (pour ce lieu). *Sources : Ferrari 1984 p. 31 ; Gentil 1923 p. 48 ; Wiktionary, s.v. Castanea.*
- **Catapodium** (genre ; grec) : « petit pied plaqué ». De kata et de podion (petit pied) : les épillets, presque sans pédicelle, sont collés contre l'axe de l'épi (Gentil comprend kata comme « auprès », Ferrari comme « dessous »). Nom actuel (GBIF/WCVP 2026) de l'ancien Scleropoa. *Sources : Ferrari 1984 p. 31 ; Gentil 1923 p. 49.*
- **Cedrus** (genre ; grec) : du grec kedros, passé en latin. Théis cite l'idée d'un mot lié à « brûler » (bois à encens) mais penche pour un nom de lieu. *Sources : Théis 1810, s.v. Pinus ; Wiktionary, s.v. Cedrus.*
- **Cenchrus** (genre ; grec) : nom grec du millet, kenchros. Cette graminée en rappelle la panicule serrée en épi ; Théis note aussi que plusieurs villes antiques s'appelaient Cenchrées. Nom actuel (GBIF/WCVP 2026) de l'ancien Pennisetum. *Sources : Théis 1810, s.v. Cenchrus ; Wiktionary, s.v. Cenchrus.*
- **Centaurea** (genre ; grec) : plante du centaure Chiron, qui se serait soigné une blessure avec elle. *Sources : Ferrari 1984 p. 32 ; Théis 1810, s.v. Centaurea ; Gentil 1923 p. 49.*
- **Centunculus** (genre ; latin) : « petit rapiéçage ». Pline cite ce nom italien d'une plante qui tapisse les champs ; Théis le tire de cento, l'étoffe faite de pièces. Ancien nom (Ferrari 1984) : Centunculus → nom actuel : Lysimachia (GBIF/WCVP 2026), la centenille est Lysimachia minima. *Sources : Ferrari 1984 p. 32 ; Gentil 1923 p. 51 ; Théis 1810, s.v. Centunculus.*
- **Cerasus** (genre ; latin) : « de Cérasonte ». Le cerisier tiendrait son nom de Cérasonte, port du Pont sur la mer Noire ; selon Gentil, c'est Lucullus qui l'en ramena à Rome en 68 av. J.-C. Ancien nom (Ferrari 1984) : Cerasus → nom actuel : Prunus (GBIF/WCVP 2026), le merisier est Prunus avium. *Sources : Ferrari 1984 p. 33 ; Gentil 1923 p. 51.*
- **Ceratocephalus** (genre ; grec) : « tête à cornes ». De keras (la corne) et de kephalê (la tête) : les petits fruits forment une tête hérissée de becs. Ancien nom (Ferrari 1984) : Ceratocephalus → nom actuel : Ranunculus (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 33 ; Gentil 1923 p. 52.*
- **Ceterach** (genre ; arabe) : nom arabe de la plante. Cette petite fougère des murs, couverte d'écailles dorées au revers, a gardé son nom arabe latinisé. Ancien nom (Ferrari 1984) : Ceterach → nom actuel : Asplenium (GBIF/WCVP 2026), soit Asplenium ceterach. *Sources : Ferrari 1984 p. 33 ; Gentil 1923 p. 53.*
- **Chaenorhinum** (genre ; grec) : « museau qui bâille ». De chainein (bâiller) et de rhis, rhinos (le museau, le nez), pour la fleur entrouverte. Ancienne graphie chez Ferrari : Chaenorrhinum. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 34.*
- **Chaerophyllum** (genre ; grec) : « feuille qui réjouit ». De chairein (se réjouir) et phyllon (feuille) : un feuillage d'un vert gai ; Gentil cite aussi, en doutant, une plante qui rendrait joyeux. Nom actuel (GBIF/WCVP 2026) de l'ancien Physocaulis de Ferrari. *Sources : Ferrari 1984 p. 34 ; Gentil 1923 p. 53.*
- **Chamagrostis** (genre ; grec) : « agrostide à ras de terre ». De chamai (à terre, donc nain) et de agrôstis : une toute petite graminée. Ancien nom (Ferrari 1984) : Chamagrostis → nom actuel : Mibora (GBIF/WCVP 2026), soit Mibora minima. *Sources : Ferrari 1984 p. 34 ; Gentil 1923 p. 53.*
- **Cheiranthus** (genre ; arabe et grec) : « fleur de giroflée ». Le nom associe kheyri, mot arabe désignant la giroflée, au grec anthos ; Gentil le comprend lui aussi comme « à fleurs de giroflée ». Ancien nom (Ferrari 1984) : Cheiranthus → nom actuel : Erysimum (GBIF/WCVP 2026), la giroflée des murailles est Erysimum cheiri. *Sources : Ferrari 1984 p. 35 ; Gentil 1923 p. 34.*
- **chinensis** (épithète ; latin moderne) : de Chine. Même forme au féminin, neutre chinense. Le latin des botanistes a une autre forme, sinensis, tirée de Sinae, les Chinois : c'est celle de l'oranger doux, Citrus sinensis. *Sources : Ferrari 1984 p. 140 ; Wiktionary, s.v. chinensis et Sinensis.*
- **Chlora** (genre ; grec) : « vert-jaune ». De chlôros, à cause des feuilles glauques ; Gentil rappelle que le mot veut aussi dire jaune, couleur de la fleur. Ancien nom (Ferrari 1984) : Chlora → nom actuel : Blackstonia (GBIF/WCVP 2026), la chlore perfoliée est Blackstonia perfoliata. *Sources : Ferrari 1984 p. 35 ; Gentil 1923 p. 55 ; Théis 1810, s.v. Chlora.*
- **Chrysanthemum** (genre ; grec) : « fleur d'or » (chrysos + anthemon). Le genre a été scindé : la marguerite (ex. C. leucanthemum) est devenue Leucanthemum vulgare, le chrysanthème des moissons Glebionis segetum ; le chrysanthème des fleuristes reste Chrysanthemum ×morifolium (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 35 ; Théis 1810, s.v. Chrysanthemum ; Gentil 1923 p. 55.*
- **Cichorium** (genre ; grec) : latinisé du grec kichorion, d'origine probablement égyptienne. C'est le genre de la chicorée et de l'endive. *Sources : Ferrari 1984 p. 36 ; Théis 1810, s.v. Cichorium ; Gentil 1923 p. 56.*
- **Cistus** (genre ; grec) : du grec kistos, nom de ces arbrisseaux, rapproché de kistê, « capsule », pour la forme du fruit. *Sources : Ferrari 1984 p. 37 ; Théis 1810, s.v. Cistus ; Gentil 1923 p. 57.*

- **Citrullus** (genre ; latin moderne) : diminutif de citrus, « petit citron », sans doute pour la couleur ou l'odeur de certains fruits. C'est le genre de la pastèque. **une seule source** (Wiktionary). *Sources : Wiktionary, s.v. Citrullus ; Ferrari 1984 p. 37 (genre cité sans étymologie).*
- **citrumelo** (nom d'hybride ; anglais) : citrus + pomelo. Mot-valise de 1907 attribué à Swingle pour les hybrides d'oranger trifolié et de pomelo (*C. ×paradisi*), utilisés comme porte-greffes. *Sources : Wiktionnaire 2026, s.v. citrumelo ; Wiktionary 2026, s.v. citrumelo.*
- **Citrus** (genre ; latin) : nom latin du citronnier et du cédratier. Le mot viendrait du grec kédros, peut-être par l'étrusque ; Théis écarte l'idée d'une ville de Judée appelée Citron. Nom accepté : Citrus L. 1753 (GBIF/WCVP 2026), qui absorbe aujourd'hui Poncirus, Fortunella, Microcitrus, Eremocitrus et Clymenia. *Sources : Ferrari 1984 p. 37 ; Théis 1810, s.v. Citrus ; Wiktionary 2026, s.v. citrus ; GBIF/WCVP 2026.*
- **Clarkia** (genre ; nom de personne) : « plante de Clark ». Ferrari la dédie à un général Clarke ; Burkhardt à l'explorateur américain William Clark. Nom actuel (GBIF/WCVP 2026) de l'ancien Godetia. *Sources : Ferrari 1984 p. 37 ; Burkhardt 2018, s.v. Clarkia.*
- **Clematis** (genre ; grec) : de klêma, « sarment », pour les tiges grimpantes de la clématite. *Sources : Ferrari 1984 p. 37 ; Gentil 1923 p. 58.*
- **clementina** (épithète ; français) : la clémentine. Le nom vient du frère Clément (Vital Rodier), qui obtint le fruit vers 1902 à l'orphelinat de Misserghin, en Algérie. - **Clinopodium** (genre ; grec) : « pied de lit ». De klinê (le lit) et de pous, podos (le pied) : les verticilles de fleurs serrés rappellent une roulette de pied de lit. Nom actuel (GBIF/WCVP 2026) de l'ancien Calamintha. *Sources : Gentil 1923 p. 38 ; Théis 1810, s.v. Clinopodium.*
- **Clymenia** (genre ; grec) : Clymène, Océanide de la mythologie grecque, compagne d'Hélios et mère de Phaéton et des Héliades. Ancien nom : Clymenia polyandra → nom actuel : Citrus polyandra Tanaka (GBIF/WCVP 2026) ; GBIF accepte encore Clymenia polyandra. *Sources : Burkhardt 2018, s.v. Clymenia ; Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **Cnicus** (genre ; grec) : nom grec du carthame. Ferrari et Gentil le relient au carthame à fleurs orangées, couleur safran ; Théis le tire d'un verbe qui veut dire piquer. Ancien nom (Ferrari 1984) : Cnicus → nom actuel : Centaurea (GBIF/WCVP 2026), le chardon béni est Centaurea benedicta. *Sources : Ferrari 1984 p. 37 ; Gentil 1923 p. 58 ; Théis 1810, s.v. Cnicus.*

M.Hiroe (GBIF/WCVP 2026) : l'épithète survit comme nom de forme ; GBIF ne reconnaît que le genre. *Sources : Wiktionary 2026, s.v. deliciosus ; GBIF/WCVP 2026.*

- **depressa** (épithète ; latin) : aplatie, déprimée. Sans doute pour le fruit aplati aux pôles (à notre avis). **une seule source** (Ferrari). - **Dianthus** (genre ; grec) : « fleur de Zeus » (Dios + anthos), pour la beauté et le parfum de l'œillet. *Sources : Ferrari 1984 p. 47 ; Théis 1810, s.v. Dianthus ; Gentil 1923 p. 69.*

- **Dioscorea** (genre ; nom de personne) : dédié à Dioscoride (Ier siècle), médecin grec des armées romaines dont le traité De materia medica a servi de manuel des plantes médicinales pendant quinze siècles. Nom actuel (GBIF/WCVP 2026) de l'ancien Tamus : le tamier est Dioscorea communis. **une seule source** (pour le détail de la vie de Dioscoride). *Sources : Ferrari 1984 p. 47 ; Burkhardt 2018, s.v. Dioscorea.*
- **Diospyros** (genre ; grec) : « blé de Zeus » (Dios + pyros), soit nourriture divine, pour les fruits du kaki et du plaqueminier. *Sources : Ferrari 1984 p. 48 ; Wiktionary, s.v. Diospyros.*
- **Dittrichia** (genre ; nom de personne) : « plante de Dittrich ». Dédiée au botaniste Manfred Dittrich (né en 1934), spécialiste des composées. Nom actuel (GBIF/WCVP 2026) de l'ancien Cupularia. **une seule source** (Burkhardt). *Sources : Burkhardt 2018, s.v. Dittrichia.*
- **Dorycnium** (genre ; grec) : nom grec antique d'une plante qu'on ne sait plus identifier. Gentil y lit dory (la lance) et un verbe signifiant « frotter » : la plante aurait servi à empoisonner des armes. Ancien nom (Ferrari 1984) : Dorycnium → nom actuel : Lotus (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 48 ; Gentil 1923 p. 72.*
- **Draba** (genre ; grec) : « âcre ». De drabê : plusieurs espèces ont un suc piquant ; Théis juge toutefois cette origine douteuse. Nom actuel (GBIF/WCVP 2026) de l'ancien Erophila. *Sources : Ferrari 1984 p. 49 ; Gentil 1923 p. 72 ; Théis 1810, s.v. Draba.*
- **Drimia** (genre ; grec) : « l'âcre ». Du grec drimys, piquant, âcre. Nom actuel (GBIF/WCVP 2026) de l'ancien Urginea : la scille maritime est Drimia maritima. **une seule source** (Wiktionary). *Sources : Wiktionary, s.v. Drimia.*
- **Duchesnea** (genre ; nom de personne) : « plante de Duchesne ». Dédiée au botaniste Antoine Nicolas Duchesne, mort en 1827. Ancien nom (Ferrari 1984) : Duchesnea → nom actuel : Potentilla (GBIF/WCVP 2026), le faux fraisier est Potentilla indica. *Sources : Ferrari 1984 p. 49 ; Burkhardt 2018, s.v. Duchesnea.*

### E

- **Echinacea** (genre ; latin moderne) : de echinus, « hérisson, oursin », pour le cœur épineux de la fleur. **une seule source** (Wiktionary). *Sources : Wiktionary, s.v. Echinacea.*
- **Echinospermum** (genre ; grec) : « graine hérisson ». De echinos (le hérisson) et de sperma (la graine) : les fruits sont couverts d'aiguillons. Ancien nom (Ferrari 1984) : Echinospermum → nom actuel : Lappula (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 50 ; Gentil 1923 p. 73.*
- **edulis** (épithète ; latin) : comestible, bon à manger. Tiré du verbe edere, manger ; même forme au féminin, neutre edule. Gentil le donne pour un lotier aux fruits comestibles, Lotus edulis. *Sources : Ferrari 1984 p. 148 ; Gentil 1923 p. 128 ; Wiktionary, s.v. edulis.*
- **elegans** (épithète ; latin) : élégant, gracieux. Même forme aux trois genres. À l'origine, le mot désignait celui qui sait choisir avec soin, de la famille du verbe eligere, choisir ; **une seule source** (Wiktionary). *Sources : Ferrari 1984 p. 148 ; Gentil 1923 p. 136 ; Wiktionary, s.v. elegans.*
- **Eleocharis** (genre ; grec) : « grâce des marais ». De helos (le marais) et de charis (la grâce) : un joli scirpe des lieux humides. Ancienne graphie chez Ferrari : Heleocharis. *Sources : Ferrari 1984 p. 63 ; Gentil 1923 p. 74.*
- **Elodea** (genre ; grec) : « des marais ». De helôdês (marécageux), pour son milieu ; l'élodée du Canada, américaine, a gagné l'Europe au XIXe siècle. Ancienne graphie chez Ferrari : Helodea. *Sources : Ferrari 1984 p. 64 ; Gentil 1923 p. 74 ; Théis 1810, s.v. Elodea.*
- **Endymion** (genre ; grec) : nom mythologique. Endymion est le berger de la mythologie grecque aimé de Séléné, la Lune, et endormi pour toujours. Ancien nom (Ferrari 1984) : Endymion → nom actuel : Hyacinthoides (GBIF/WCVP 2026), la jacinthe des bois est Hyacinthoides non-scripta. *Sources : Ferrari 1984 p. 51 ; Gentil 1923 p. 75.*
- **Epipogium** (genre ; grec) : « sur la barbe ». De epi (sur) et de pogôn (la barbe) ; Ferrari l'explique par la vie de cette orchidée sans feuilles sur les racines d'autres plantes. Ancienne graphie chez Ferrari : Epipogon. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 52.*
- **Eremocitrus** (genre ; grec) : agrume du désert. De erēmos, désert, et Citrus (à notre avis) : c'est la lime du désert australien. Swingle a créé le genre en 1914, avec pour type Triphasia glauca Lindl. **une seule source** (Swingle et Reece). Ancien nom : Eremocitrus glauca → nom actuel : Citrus glauca (GBIF/WCVP 2026) ; GBIF accepte toujours le genre Eremocitrus. *Sources : Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **Erica** (genre ; grec) : du grec ereikê, nom de la bruyère, parfois rapproché de ereikô, « briser ». *Sources : Ferrari 1984 p. 53 ; Théis 1810, s.v. Erica ; Gentil 1923 p. 77.*
- **Eriobotrya** (genre ; grec) : « grappe laineuse » (erion + botrys), pour les grappes duveteuses du néflier du Japon. *Sources : Ferrari 1984 p. 53 ; Wiktionary, s.v. Eriobotrya.*
- **Eriophorum** (genre ; grec) : « porte-laine ». De erion (la laine) et de pherein (porter) : les fruits portent de longues soies blanches. Nom actuel (GBIF/WCVP 2026) de l'ancien Linagrostis. *Sources : Ferrari 1984 p. 53 ; Théis 1810, s.v. Eriophorum.*
- **Erophila** (genre ; grec) : « amie du printemps ». De êr (le printemps) et de philos (ami) : une des toutes premières fleurs de l'année. Ancien nom (Ferrari 1984) : Erophila → nom actuel : Draba (GBIF/WCVP 2026), la drave printanière est Draba verna. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 54.*
- **Eruca** (genre ; latin) : nom latin de la roquette, peut-être lié à urere, « brûler », pour son goût piquant. *Sources : Ferrari 1984 p. 54 ; Théis 1810, s.v. Brassica ; Gentil 1923 p. 79.*
- **Ervilia** (genre ; latin) : ancien nom latin d'une vesce. Ferrari y reconnaît le nom que les Romains donnaient à la vesce. Ancien nom (Ferrari 1984) : Ervilia → nom actuel : Vicia (GBIF/WCVP 2026), soit Vicia ervilia. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 54.*
- **Erysimum** (genre ; grec) : « qui sauve le chant ». Ferrari et Gentil y voient le mot grec du chant : l'herbe au chantre passait pour soigner la voix et la toux. Nom actuel (GBIF/WCVP 2026) de l'ancien Cheiranthus. *Sources : Ferrari 1984 p. 54 ; Gentil 1923 p. 80.*
- **Eschscholzia** (genre ; nom de personne) : « plante d'Eschscholtz ». Dédiée au naturaliste germano-balte Johann Friedrich Eschscholtz (1793-1831). Ancienne graphie chez Ferrari : Eschscholtzia. *Sources : Ferrari 1984 p. 55 ; Burkhardt 2018, s.v. Eschscholzia.*
- **Euonymus** (genre ; grec) : « au bon nom ». De eu (bien) et de onoma (le nom) ; Théis pense à un nom ancien perdu, Gentil au bonnet carré du fruit. Ancienne graphie chez Ferrari : Evonymus. *Sources : Ferrari 1984 p. 55 ; Gentil 1923 p. 85 ; Théis 1810, s.v. Evonymus.*
- **Euphorbia** (genre ; grec) : dédié à Euphorbe, médecin grec de Juba II, roi de Maurétanie, qui fut le premier à employer la plante ; Théis ajoute qu'il était le frère de Musa, lui-même au service de l'empereur Auguste. *Sources : Ferrari 1984 p. 55 ; Théis 1810, s.v. Euphorbia ; Gentil 1923 p. 81 ; Burkhardt 2018, s.v. Euphorbia.*
- **europaeus** (épithète ; latin, du grec) : d'Europe. Emprunté au grec Eurôpaios ; formes europaea et europaeum, comme la sanicle d'Europe, Sanicula europaea. *Sources : Gentil 1923 p. 192 ; Wiktionary, s.v. europaeus et Europaeus.*
- **Evax** (genre ; nom de personne) : « plante d'Evax ». Dédiée à Evax, roi et médecin d'Arabie, qu'on disait contemporain de Néron. Ancien nom (Ferrari 1984) : Evax → nom actuel : Filago (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 55 ; Gentil 1923 p. 84 ; Burkhardt 2018, s.v. Evax.*

### F

- **Fagus** (genre ; grec) : du grec phagein, « manger », pour les faines comestibles du hêtre (Gentil ajoute avec humour : au moins pour les écureuils). *Sources : Ferrari 1984 p. 56 ; Théis 1810, s.v. Fagus ; Gentil 1923 p. 85.*

- **floridana** (épithète ; latin moderne) : de Floride (à notre avis). Publié par Ingram et Moore sous ×Citrofortunella pour un hybride obtenu en Floride. **une seule source** (à notre avis). - **Foeniculum** (genre ; latin) : « petit foin » (fenum), pour les feuilles fines du fenouil et son odeur de foin. *Sources : Ferrari 1984 p. 57 ; Théis 1810, s.v. Anethum ; Gentil 1923 p. 87.*

- **Forsythia** (genre ; latin moderne) : dédié par Vahl à William Forsyth (1737-1804), jardinier écossais des jardins royaux anglais. *Sources : Ferrari 1984 p. 57 ; Burkhardt 2018, s.v. Forsythia ; Wiktionary, s.v. Forsythia.*
- **Fortunella** (genre ; latin moderne) : en l'honneur de Robert Fortune (1812-1880), botaniste écossais. Ancien nom : Fortunella → nom actuel : Citrus (GBIF/WCVP 2026), les kumquats étant réunis sous Citrus japonica ; GBIF ne trouve plus le nom Fortunella. *Sources : Burkhardt 2018, s.v. Fortunella ; Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **Fragaria** (genre ; latin) : de fraga, « fraises » ; Gentil le rattache plutôt à fragrans, « parfumé », pour l'odeur du fruit. *Sources : Ferrari 1984 p. 57 ; Gentil 1923 p. 87 ; Wiktionary, s.v. Fragaria.*

- **Fraxinus** (genre ; latin) : nom latin du frêne, d'origine incertaine ; on l'a rapproché du grec phraxis, « clôture », pour les haies. *Sources : Ferrari 1984 p. 58 ; Théis 1810, s.v. Fraxinus ; Gentil 1923 p. 87.*
- **Freesia** (genre ; nom de personne) : « plante de Freese ». Dédiée au médecin allemand Friedrich Heinrich Theodor Freese. Ancienne graphie chez Ferrari : Freesea. *Sources : Ferrari 1984 p. 58 ; Burkhardt 2018, s.v. Freesia.*
- **fruticosus** (épithète ; latin) : arbustif, qui forme un buisson ligneux. Tiré de frutex, l'arbrisseau ; formes fruticosa et fruticosum. *Sources : Ferrari 1984 p. 153 ; Gentil 1923 p. 189 ; Wiktionary, s.v. fruticosus.*
- **Fuchsia** (genre ; latin moderne) : dédié par Plumier au médecin et botaniste allemand Leonhart Fuchs, né en 1501, auteur d'un herbier illustré célèbre. *Sources : Ferrari 1984 p. 58 ; Théis 1810, s.v. Fuchsia ; Burkhardt 2018, s.v. Fuchsia.*

### G

- **Galanthus** (genre ; grec) : « fleur de lait » (gala + anthos), pour la blancheur du perce-neige. *Sources : Ferrari 1984 p. 59 ; Théis 1810, s.v. Galanthus ; Gentil 1923 p. 89.*

- **Gardenia** (genre ; latin moderne) : dédié au médecin et naturaliste écossais Alexander Garden (1730-1791), établi en Caroline du Sud. *Sources : Théis 1810, s.v. Gardenia ; Burkhardt 2018, s.v. Gardenia ; Wiktionary, s.v. Gardenia.*

- **Genistella** (genre ; latin) : « petit genêt ». Diminutif de genista. Ancien nom (Ferrari 1984) : Genistella → nom actuel : Genista (GBIF/WCVP 2026), le genêt ailé est Genista sagittalis. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 60.*
- **Gentiana** (genre ; latin) : de Gentius, roi d'Illyrie, qui aurait découvert les vertus de la gentiane. *Sources : Ferrari 1984 p. 60 ; Théis 1810, s.v. Gentiana ; Gentil 1923 p. 91 ; Burkhardt 2018, s.v. Gentiana.*

- **Glaux** (genre ; grec) : « glauque ». De glaukos (d'un vert terne, bleuté) : Dioscoride nommait ainsi une plante du bord de mer aux feuilles vert pâle. - **Gleditsia** (genre ; nom de personne) : « plante de Gleditsch ». Dédiée au botaniste de Berlin Johann Gottlieb Gleditsch (1714-1786). Ancienne graphie chez Ferrari : Gleditschia. *Sources : Ferrari 1984 p. 61 ; Théis 1810, s.v. Gleditsia ; Burkhardt 2018, s.v. Gleditsia.*

- **Gouffeia** (genre ; nom de personne) : « plante de Gouffé ». Nom donné en l'honneur de Gouffé de la Cour, qui dirigeait au début du XIXe siècle le jardin des plantes de Marseille. Ancien nom (Ferrari 1984) : Hermodactylus → nom actuel : Iris (GBIF/WCVP 2026), soit Iris tuberosa. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 65.*
- **Hibiscus** (genre ; grec) : du grec hibiskos, ancien nom de la guimauve, d'origine obscure. *Sources : Ferrari 1984 p. 65 ; Théis 1810, s.v. Hibiscus ; Gentil 1923 p. 101.*
- **hindsii** (épithète ; latin moderne) : de Hinds. Le type a été récolté à Hong Kong en 1841 par Hinds. C'est le kumquat de Hong Kong, sauvage, aux fruits minuscules. **une seule source** (Swingle et Reece). Ancien nom : Fortunella hindsii → nom actuel : Citrus japonica Thunb. (GBIF/WCVP 2026). *Sources : Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **hirsutus** (épithète ; latin) : hérissé de poils raides. Même famille que hirtus, velu ; formes hirsuta et hirsutum. *Sources : Ferrari 1984 p. 156 ; Gentil 1923 p. 207 ; Wiktionary, s.v. hirsutus.*
- **hispanicus** (épithète ; latin) : d'Espagne. Tiré de Hispania, l'Espagne ; formes hispanica et hispanicum. *Sources : Ferrari 1984 p. 156 ; Gentil 1923 p. 92 ; Wiktionary, s.v. Hispanicus.*
- **Hortensia** (genre ; latin) : origine discutée. Ferrari le dédie à une Hortense, épouse d'un membre de l'expédition Bougainville ; Théis le tire de hortensis, des jardins, plante qui orne les jardins chinois. Ancien nom (Ferrari 1984) : Hortensia → nom actuel : Hydrangea (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 67 ; Théis 1810, s.v. Hortensia.*
- **Hosta** (genre ; latin moderne) : dédié au médecin et botaniste autrichien Nicolaus Thomas Host (1761-1834). Ancien nom : Funkia → nom actuel : Hosta (GBIF/WCVP 2026). *Sources : Burkhardt 2018, s.v. Hosta ; Wiktionary, s.v. Hosta.*
- **Hutchinsia** (genre ; nom de personne) : « plante de Miss Hutchins ». Dédiée à l'Irlandaise Ellen Hutchins (1785-1815), spécialiste des mousses et des algues. Ancien nom (Ferrari 1984) : Hutchinsia → nom actuel : Noccaea (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 67 ; Gentil 1923 p. 106 ; Burkhardt 2018, s.v. Hutchinsia.*
- **Hyacinthoides** (genre ; grec) : « qui ressemble à la jacinthe ». Nom de Hyacinthus suivi du suffixe -oides (semblable à). Nom actuel (GBIF/WCVP 2026) de l'ancien Endymion. **une seule source** (Gentil). *Sources : Gentil 1923 p. 197.*
- **Hyacinthus** (genre ; grec) : du jeune Hyacinthe, tué par accident par Apollon, qui fit naître de son sang une fleur. *Sources : Ferrari 1984 p. 67 ; Théis 1810, s.v. Hyacinthus ; Gentil 1923 p. 106.*
- **hybridus** (épithète ; latin) : hybride, né du croisement de deux espèces. Le latin hybrida désignait un être de sang mêlé ; Théis tire le mot du grec hybris, l'outrage, alors que le Wiktionary y voit un ancien mot latin, ibrida, seulement influencé par ce mot grec. Théis trouvait déjà que les botanistes en abusaient, et Gentil cite deux plantes nommées hybridum ou hybrida qui n'ont rien d'hybride (un pavot et une spéculaire). *Sources : Ferrari 1984 p. 156 ; Théis 1810, s.v. Hybride ; Gentil 1923 p. 156 et p. 213 ; Wiktionary, s.v. hybrida.*
- **Hydrangea** (genre ; grec) : « vase à eau » (hydôr + angos), pour la forme en coupe des fruits. Ancien nom : Hortensia → nom actuel : Hydrangea. *Sources : Ferrari 1984 p. 68 ; Théis 1810, s.v. Hydrangea ; Wiktionary, s.v. Hydrangea.*
- **Hymenocarpus** (genre ; grec) : « fruit membraneux ». De hymên (la membrane) et de karpos (le fruit) : la gousse plate, enroulée, est fine comme une membrane. Ancien nom (Ferrari 1984) : Hymenocarpus → nom actuel : Anthyllis (GBIF/WCVP 2026). **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 68.*
- **Hypericum** (genre ; grec) : deux lectures. Pour Ferrari et Gentil, hypo + ereikê, « sous la bruyère » ; pour Théis (et Gentil en second), hyper + eikôn, « au-dessus des images », car on la suspendait au-dessus des icônes contre les mauvais esprits. *Sources : Ferrari 1984 p. 68 ; Théis 1810, s.v. Hypericum ; Gentil 1923 p. 107.*
- **Hyssopus** (genre ; grec) : du grec hyssôpos, venu d'un mot hébreu désignant une plante sacrée de purification. *Sources : Ferrari 1984 p. 69 ; Gentil 1923 p. 108.*
- **hystrix** (épithète ; grec) : porc-épic. Le grec désigne l'animal à piquants ; le combava est en effet très épineux (à notre avis). Son nom français viendrait de l'île de Sumbawa. Nom accepté : Citrus hystrix DC. 1813 (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 156 ; Gentil 1923 p. 111 ; Wiktionary 2026, s.v. hystrix ; Wiktionnaire 2026, s.v. combava ; GBIF/WCVP 2026.*

### I

- **ichangensis** (épithète ; latin moderne) : d'Ichang (aujourd'hui Yichang), dans le Hubei. C'est la papeda d'Ichang. **une seule source** (Swingle et Reece). Ancien nom : Citrus ichangensis Swingle → nom actuel : Citrus cavaleriei (GBIF/WCVP 2026), même rattachement chez GBIF ; l'étymologie de cavaleriei n'a pas été vérifiée ici. *Sources : Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **Ilex** (genre ; latin) : nom latin du chêne vert, donné par Linné au houx pour ses feuilles semblables. Théis y voit un mot celtique (à notre avis, piste ancienne fragile). *Sources : Ferrari 1984 p. 69 ; Théis 1810, s.v. Ilex ; Gentil 1923 p. 109.*
- **Ilysanthes** (genre ; grec) : « fleur de la vase ». De ilys (la vase, le limon) et de anthos (la fleur), pour son habitat. Ancien nom (Ferrari 1984) : Ilysanthes → nom actuel : Lindernia (GBIF/WCVP 2026). **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 69.*
- **Ipomoea** (genre ; grec) : « semblable à ips ». Le second élément vient de homoios (semblable) ; pour ips, Théis y voit un liseron, plante très proche, et Ferrari le traduit par « ver » (graphie Ipomea chez Ferrari et Théis). Nom actuel (GBIF/WCVP 2026) de l'ancien Pharbitis. *Sources : Ferrari 1984 p. 70 ; Théis 1810, s.v. Ipomea.*
- **Iris** (genre ; grec) : « arc-en-ciel », du nom de la messagère des dieux, pour la variété des couleurs de la fleur. *Sources : Ferrari 1984 p. 70 ; Théis 1810, s.v. Iris ; Gentil 1923 p. 111.*
- **Isatis** (genre ; grec) : « qui rend lisse ». D'un verbe grec signifiant « polir » : selon Gentil, Dioscoride et Pline prêtaient au pastel le pouvoir de résorber les enflures. Nom actuel (GBIF/WCVP 2026) de l'ancien Boreava. *Sources : Ferrari 1984 p. 70 ; Gentil 1923 p. 111 ; Théis 1810, s.v. Isatis.*
- **italicus** (épithète ; latin) : d'Italie. Tiré de Italia ; formes italica et italicum, comme la scille d'Italie, Scilla italica. *Sources : Ferrari 1984 p. 158 ; Gentil 1923 p. 197 ; Wiktionary, s.v. italicus.*

### J

- **jambhiri** (épithète ; langue de l'Inde) : d'un nom indien du citron rugueux (à notre avis) ; aucun dictionnaire consulté ne donne ce mot. C'est le rough lemon, porte-greffe vigoureux. **une seule source** (à notre avis). Ancien nom : Citrus jambhiri Lush. → nom actuel : Citrus ×taitensis Risso (GBIF/WCVP 2026) ; GBIF ne trouve que le genre. *Sources : GBIF/WCVP 2026.*
- **japonica** (épithète ; latin) : du Japon. Thunberg l'a décrit en 1780 d'après les kumquats vus au Japon. Nom accepté : Citrus japonica Thunb. (GBIF/WCVP 2026), qui réunit désormais tous les kumquats autrefois en Fortunella (margarita, crassifolia, hindsii) ainsi que C. madurensis. *Sources : Ferrari 1984 p. 159 ; Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **japonicus** (épithète ; latin moderne) : du Japon. Formes japonica et japonicum ; on trouve aussi l'orthographe iaponicus. *Sources : Ferrari 1984 p. 159 ; Wiktionary, s.v. japonicus.*
- **Jasminum** (genre ; persan) : latinisé de l'arabe et du persan yasmin, nom de cette fleur parfumée. *Sources : Ferrari 1984 p. 71 ; Gentil 1923 p. 112.*
- **Juglans** (genre ; latin) : « gland de Jupiter » (Jovis glans), pour la noix, fruit jugé digne des dieux. *Sources : Ferrari 1984 p. 71 ; Théis 1810, s.v. Juglans ; Gentil 1923 p. 112.*
- **Juniperus** (genre ; latin) : nom latin du genévrier. Théis, Gentil et Ferrari le tirent d'un mot celtique, « âpre », pour le goût du fruit (à notre avis, piste ancienne fragile) ; d'autres y lisent junior + parere, « qui produit des jeunes ». *Sources : Ferrari 1984 p. 71 ; Théis 1810, s.v. Juniperus ; Gentil 1923 p. 112.*
- **junos** (épithète ; japonais) : tiré d'un nom japonais du yuzu (à notre avis). Swingle et Reece voient dans le yuzu un probable hybride de la papeda d'Ichang, ce qui expliquerait sa rusticité. **une seule source** (Wiktionary). Nom accepté : Citrus ×junos Siebold ex Tanaka (GBIF/WCVP 2026). *Sources : Wiktionary 2026, s.v. yuzu ; Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*

### K

- **Kochia** (genre ; nom de personne) : « plante de Koch ». Dédiée au botaniste allemand Wilhelm Daniel Joseph Koch (1771-1849). Ancien nom (Ferrari 1984) : Kochia → nom actuel : Bassia (GBIF/WCVP 2026), soit Bassia scoparia. *Sources : Ferrari 1984 p. 72 ; Burkhardt 2018, s.v. Kochia.*

### L

- **Lactuca** (genre ; latin) : de lac, lactis, « lait », pour le suc blanc de la laitue. *Sources : Ferrari 1984 p. 72 ; Théis 1810, s.v. Lactuca ; Gentil 1923 p. 116.*
- **Lagoseris** (genre ; grec) : « chicorée de lièvre ». De lagôs (le lièvre) et de seris (une chicorée, une salade). Ancien nom (Ferrari 1984) : Lagoseris → nom actuel : Crepis (GBIF/WCVP 2026). **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 73.*
- **lanatus** (épithète ; latin) : laineux, couvert de poils comme de la laine. Tiré de lana, la laine ; formes lanata et lanatum. *Sources : Ferrari 1984 p. 159 ; Gentil 1923 p. 48 ; Wiktionary, s.v. lanatus.*
- **Lappula** (genre ; latin) : « petite bardane ». Diminutif de lappa (la bardane) : ses fruits accrocheurs collent aux vêtements. Nom actuel (GBIF/WCVP 2026) de l'ancien Echinospermum. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 73.*
- **Lapsana** (genre ; grec) : « qui relâche ». Gentil le rattache à un verbe grec qui veut dire amollir, pour un effet laxatif. Ancienne graphie chez Ferrari : Lampsana. **une seule source** (Gentil). *Sources : Gentil 1923 p. 118 ; Ferrari 1984 p. 73 (graphie seulement).*
- **Lathyrus** (genre ; grec) : nom grec d'une légumineuse, employé par Théophraste. Une vieille explication y voyait une plante « excitante », que Théis juge déjà douteuse. - **latifolia** (épithète ; latin) : à larges feuilles. De latus, large, et folium, feuille. C'est la lime de Tahiti, ou lime de Perse, la lime sans pépins. Nom accepté : Citrus ×latifolia (Yu.Tanaka) Yu.Tanaka (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 160 ; Wiktionary 2026, s.v. latus ; Morton 1987, Tahiti lime ; GBIF/WCVP 2026.*
- **latipes** (épithète ; latin) : à pied large. De latus, large, et pes, pied (à notre avis, sans doute pour le pétiole très ailé). Papeda du nord-est de l'Inde. - **Laurus** (genre ; latin) : nom latin du laurier. Théis propose un mot celtique, blawr, « vert » ; **une seule source** (pour cette piste). *Sources : Ferrari 1984 p. 74 ; Théis 1810, s.v. Laurus.*
- **Lavandula** (genre ; latin médiéval) : de lavare, « laver », car on parfumait l'eau du bain et le linge avec la lavande. *Sources : Ferrari 1984 p. 74 ; Théis 1810, s.v. Lavandula ; Gentil 1923 p. 118.*
- **Lavatera** (genre ; nom de personne) : « plante des Lavater ». Dédiée aux Lavater, famille de naturalistes suisses du XVIIe siècle. Ancien nom (Ferrari 1984) : Lavatera → nom actuel : Malva (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 74 ; Burkhardt 2018, s.v. Lavatera.*
- **Legousia** (genre ; nom de personne) : « plante de Le Gouz ». Nom donné en l'honneur de Bénigne Le Gouz de Gerland, à l'origine du jardin des plantes de Dijon. Ancienne graphie chez Ferrari : Legouzia. *Sources : Ferrari 1984 p. 74 ; Burkhardt 2018, s.v. Legousia.*
- **Lepidium** (genre ; grec) : de lepis, « écaille », pour la forme des petites silicules du cresson alénois. *Sources : Ferrari 1984 p. 75 ; Théis 1810, s.v. Lepidium ; Gentil 1923 p. 121.*
- **Leucorchis** (genre ; grec) : « orchis blanc ». De leukos (blanc) et de orchis : ses petites fleurs sont blanchâtres. Ancien nom (Ferrari 1984) : Leucorchis → nom actuel : Pseudorchis (GBIF/WCVP 2026), soit Pseudorchis albida. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 75.*
- **Leuzea** (genre ; nom de personne) : « plante de Deleuze ». Dédiée au naturaliste Joseph Philippe François Deleuze (1753-1835). Ancien nom (Ferrari 1984) : Leuzea → nom actuel : Rhaponticum (GBIF/WCVP 2026), la pomme de pin est Rhaponticum coniferum. *Sources : Ferrari 1984 p. 75 ; Burkhardt 2018, s.v. Leuzea.*
- **Lilium** (genre ; latin) : nom latin du lis, apparenté au grec leirion. Théis le rapproche d'un mot celtique li, « blanc » (à notre avis, piste ancienne fragile). *Sources : Ferrari 1984 p. 76 ; Théis 1810, s.v. Lilium ; Gentil 1923 p. 123.*
- **limon** (épithète ; arabe) : le citron. Théis le tire de l'arabe limoun, Ferrari du turc, le Wiktionnaire de l'italien limone et de l'ottoman limon : les sources divergent sur l'étape, toutes passent par l'Orient. Nom actuel : Citrus ×limon (L.) Osbeck (GBIF/WCVP 2026), désormais écrit avec le signe × car c'est un hybride ; GBIF dit C. limon. *Sources : Théis 1810, s.v. Limonia ; Ferrari 1984 p. 161 ; Wiktionnaire 2026, s.v. limon ; GBIF/WCVP 2026.*
- **limonia** (épithète ; latin moderne) : semblable au citron. Même racine que limon, venue de l'arabe selon Théis. Osbeck l'a donné à une lime de Canton, la lime Rangpur des porte-greffes (à notre avis). Ancien nom : Citrus limonia Osbeck → nom actuel : Citrus ×limon (GBIF/WCVP 2026), même rattachement chez GBIF. *Sources : Théis 1810, s.v. Limonia ; Ferrari 1984 p. 161 ; GBIF/WCVP 2026.*
- **Linagrostis** (genre ; grec) : « lin des champs ». De linon (le lin) et de agros (le champ) : les touffes de soies blanches rappellent la filasse. Ancien nom (Ferrari 1984) : Linagrostis → nom actuel : Eriophorum (GBIF/WCVP 2026). **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 77.*
- **Lindernia** (genre ; nom de personne) : « plante de Lindern ». Dédiée au médecin et botaniste de Strasbourg Franz Balthasar von Lindern (1682-1755). Nom actuel (GBIF/WCVP 2026) de l'ancien Ilysanthes. *Sources : Ferrari 1984 p. 77 ; Gentil 1923 p. 125 ; Burkhardt 2018, s.v. Lindernia.*
- **Linum** (genre ; latin) : nom latin du lin, apparenté au grec linon ; le mot a donné « linge » et « ligne ». *Sources : Ferrari 1984 p. 77 ; Théis 1810, s.v. Linum ; Gentil 1923 p. 125.*
- **longifolius** (épithète ; latin) : à longues feuilles. Assemblage de longus (long) et folium (feuille) ; formes longifolia et longifolium. *Sources : Ferrari 1984 p. 161 ; Gentil 1923 p. 164 ; Wiktionary, s.v. longifolius.*
- **Lonicera** (genre ; latin moderne) : dédié au médecin et botaniste allemand Adam Lonitzer (Lonicerus, 1528-1586). C'est le genre du chèvrefeuille. *Sources : Ferrari 1984 p. 78 ; Théis 1810, s.v. Lonicera ; Gentil 1923 p. 127 ; Burkhardt 2018, s.v. Lonicera.*
- **Loroglossum** (genre ; grec) : « langue en lanière ». De lôros (la courroie, ici étroite) et de glôssa (la langue), pour le long labelle enroulé. Ancien nom (Ferrari 1984) : Loroglossum → nom actuel : Himantoglossum (GBIF/WCVP 2026), l'orchis bouc est Himantoglossum hircinum. *Sources : Ferrari 1984 p. 79 ; Gentil 1923 p. 128.*
- **Lotus** (genre ; grec) : vieux nom grec porté par plusieurs plantes sans rapport ; Pline distinguait déjà un lotus arbre, un lotus d'Égypte et un lotus herbacé. Nom actuel (GBIF/WCVP 2026) de l'ancien Tetragonolobus. *Sources : Gentil 1923 p. 128 ; Théis 1810, s.v. Lotus.*
- **Lupinus** (genre ; latin) : nom latin du lupin, souvent rapproché de lupus, « loup ». Pline notait déjà que le lupin enrichit le sol. *Sources : Ferrari 1984 p. 79 ; Théis 1810, s.v. Lupinus ; Gentil 1923 p. 129.*
- **luteus** (épithète ; latin) : jaune. Formes lutea et luteum, comme le réséda jaune, Reseda lutea. Le mot viendrait de lutum, la gaude, un réséda des teinturiers qui donnait le jaune ; **une seule source** (Wiktionary, qui propose aussi une autre origine). *Sources : Ferrari 1984 p. 162 ; Gentil 1923 p. 181 ; Wiktionary, s.v. luteus.*
- **Lychnis** (genre ; grec) : « lampe ». De lychnos : les feuilles cotonneuses d'une espèce servaient, dit Pline, à faire des mèches de lampe. Ancien nom (Ferrari 1984) : Lychnis → nom actuel : Silene (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 79 ; Gentil 1923 p. 130 ; Théis 1810, s.v. Lychnis.*
- **Lysimachia** (genre ; nom de personne) : dédié à un Lysimaque de l'Antiquité, sur l'identité duquel les sources divergent : un médecin pour Ferrari et Gentil ; un roi pour Théis et Burkhardt, que Pline crédite de la découverte de la plante, roi de Sicile selon Linné ou plutôt Lysimaque de Thrace (vers 360-281 av. J.-C.), ancien général d'Alexandre, selon Bauhin et Burkhardt. Nom actuel (GBIF/WCVP 2026) de l'ancien Trientalis. *Sources : Ferrari 1984 p. 80 ; Gentil 1923 p. 131 ; Théis 1810, s.v. Lysimachia ; Burkhardt 2018, s.v. Lysimachia.*
- **Lythrum** (genre ; grec) : « sang ». Du grec lythron, le sang versé, pour la couleur rouge pourpré des fleurs de la salicaire. Nom actuel (GBIF/WCVP 2026) de l'ancien Peplis : le pourpier d'eau est Lythrum portula. *Sources : Ferrari 1984 p. 80 ; Gentil 1923 p. 131.*

### M

- **Maclura** (genre ; nom de personne) : dédié à William Maclure (1763-1840), géologue né en Écosse et établi aux États-Unis. Nom actuel (GBIF/WCVP 2026) de l'ancien Toxylon : l'oranger des Osages est Maclura pomifera. *Sources : Burkhardt 2018, s.v. Maclura ; Wiktionary, s.v. Maclura.*
- **macrophylla** (épithète ; grec) : à grandes feuilles. De makros, grand, et phyllon, feuille. C'est l'alemow, décrit par Wester en 1915 à Cebu (Philippines), porte-greffe. Ancien nom : Citrus macrophylla Wester → nom actuel : Citrus ×aurantiifolia (GBIF/WCVP 2026), même rattachement chez GBIF. *Sources : Ferrari 1984 p. 162 ; Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **macrophyllus** (épithète ; grec) : à grandes feuilles. Assemblage des mots grecs makros (grand, long) et phyllon (feuille) ; formes macrophylla et macrophyllum. *Sources : Ferrari 1984 p. 162 ; Gentil 1923 p. 179 ; Wiktionary, s.v. macrophyllus.*
- **madurensis** (épithète ; latin moderne) : de Madura (à notre avis), nom de lieu que Loureiro (1790) ne permet pas de situer avec certitude dans nos sources. **une seule source** (Swingle et Reece). Ancien nom : Citrus madurensis Lour. → nom actuel : Citrus japonica Thunb. (GBIF/WCVP 2026). *Sources : Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **Magnolia** (genre ; nom de personne, français) : en l'honneur de Pierre Magnol. Linné a dédié le genre à ce médecin et botaniste de Montpellier (1638-1715), qui dirigea le jardin botanique de la ville. *Sources : Théis 1810, s.v. Magnolia ; Burkhardt 2018, s.v. Magnolia.*
- **major** (épithète ; latin) : plus grand. Comparatif de magnus, grand ; même forme au féminin, neutre majus. Le latin classique l'écrivait maior. Il s'oppose à minor. *Sources : Ferrari 1984 p. 162 ; Gentil 1923 p. 142 ; Wiktionary, s.v. maior.*
- **Majorana** (genre ; latin médiéval) : nom d'origine obscure. Le latin médiéval majorana a donné « marjolaine » ; on l'a rapproché, sans certitude, de amaracus. Ancien nom (Ferrari 1984) : Majorana → nom actuel : Origanum (GBIF/WCVP 2026), la marjolaine est Origanum majorana. *Sources : Ferrari 1984 p. 80 ; Wiktionnaire, s.v. marjolaine.*
- **Malachium** (genre ; grec) : « mou ». Du grec malakos : la tige du céraiste d'eau est tendre, sans tenue. Ancien nom (Ferrari 1984) : Malachium (synonyme de Myosoton) → nom actuel : Stellaria (GBIF/WCVP 2026), soit Stellaria aquatica. *Sources : Ferrari 1984 p. 80 ; Gentil 1923 p. 132.*
- **Malcolmia** (genre ; nom de personne) : dédié à un pépiniériste anglais nommé Malcolm, sans doute William Malcolm (mort en 1798), installé près de Londres à Kennington puis Stockwell, ou son fils du même nom. Ferrari écrit Malcomia (orthographe corrigée depuis) et place l'homme au XVIIIe siècle, Gentil au XIXe. *Sources : Ferrari 1984 p. 80 ; Gentil 1923 p. 132 ; Burkhardt 2018, s.v. Malcolmia.*
- **Malus** (genre ; latin, d'origine celtique) : le pommier. Le latin malus viendrait d'un mot celtique proche de mel ou mal. Ferrari range encore le pommier dans Pirus, mais Malus et Pyrus sont aujourd'hui deux genres distincts (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 81 ; Gentil 1923 p. 132 ; Théis 1810, s.v. Pyrus.*
- **Malva** (genre ; latin, du grec) : la plante qui amollit. Le nom se rattache au grec malakos, mou, car la mauve est une plante émolliente, qui adoucit. Ancien nom (Ferrari 1984) : Lavatera (voir Lavatera) → nom actuel : Malva (GBIF/WCVP 2026, ex. Lavatera arborea devenu Malva arborea). *Sources : Ferrari 1984 p. 81 et p. 74 ; Gentil 1923 p. 132 ; Théis 1810, s.v. Malva.*
- **margarita** (épithète ; latin) : la perle (à notre avis), pour le petit fruit ovale et brillant d'un kumquat. Loureiro l'a nommé Citrus margarita, qui sert de type au genre Fortunella. **une seule source** (Swingle et Reece). Ancien nom : Fortunella margarita → nom actuel : Citrus japonica Thunb. (GBIF/WCVP 2026). *Sources : Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **maritimus** (épithète ; latin) : du bord de mer. Tiré de mare, la mer ; formes maritima et maritimum, comme le glaux maritime, Glaux maritima. *Sources : Ferrari 1984 p. 163 ; Gentil 1923 p. 95 ; Wiktionary, s.v. maritimus.*

- **Merendera** (genre ; origine incertaine) : étymologie discutée. - **microcarpa** (épithète ; grec) : à petits fruits. De mikros, petit, et karpos, fruit. C'est le calamondin, nom tiré du pampangan des Philippines. Ancien nom : Microcitrus → nom actuel : Citrus (GBIF/WCVP 2026) ; GBIF accepte toujours le genre Microcitrus. *Sources : Ferrari 1984 p. 164, s.v. - **Microlonchus** (genre ; grec) : « petite lance ». De mikros (petit) et lonchê (lance). Ancien nom (Ferrari 1984) : Microlonchus → nom actuel : Mantisalca (GBIF/WCVP 2026), soit Mantisalca salmantica. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 83.*
- **microphyllus** (épithète ; grec) : à petites feuilles. Assemblage des mots grecs mikros (petit) et phyllon (feuille) ; formes microphylla et microphyllum, comme l'épipactis à petites feuilles, Epipactis microphylla. *Sources : Gentil 1923 p. 76 ; Wiktionary, s.v. microphyllus.*
- **minor** (épithète ; latin) : plus petit. Comparatif de parvus, petit ; même forme au féminin, neutre minus. Il s'oppose à major. *Sources : Ferrari 1984 p. 164 ; Gentil 1923 p. 142 ; Wiktionary, s.v. minor.*
- **montanus** (épithète ; latin) : des montagnes. Tiré de mons, montis, la montagne ; formes montana et montanum, comme la soldanelle des montagnes, Soldanella montana. *Sources : Ferrari 1984 p. 165 ; Gentil 1923 p. 211 ; Wiktionary, s.v. montanus.*
- **Morus** (genre ; latin, du grec moron) : le mûrier. Ferrari s'en tient au nom latin ; Théis le rapproche d'un mot celtique mor, noir, la couleur des mûres ; **une seule source** (pour ce sens). *Sources : Ferrari 1984 p. 85 ; Théis 1810, s.v. Morus.*
- **multiflorus** (épithète ; latin) : à nombreuses fleurs. Assemblage de multus (nombreux) et flos, floris (fleur) ; formes multiflora et multiflorum. *Sources : Ferrari 1984 p. 165 ; Gentil 1923 p. 127 ; Wiktionary, s.v. multiflorus.*

- **myrtifolia** (épithète ; latin) : à feuilles de myrte. De myrtus, le myrte (grec mýrtos), et folium, feuille (à notre avis). Latifolius ; GBIF/WCVP 2026.*

### N

- **nanus** (épithète ; latin, du grec) : nain. Le latin l'a pris au grec nanos ; formes nana et nanum. *Sources : Ferrari 1984 p. 166 ; Gentil 1923 p. 22 ; Wiktionary, s.v. nanus.*
- **Narcissus** (genre ; grec) : l'engourdissement. Le nom évoque narkê, la torpeur, à cause de l'odeur entêtante et des propriétés narcotiques du bulbe ; on y lit aussi le jeune Narcisse du mythe, changé en fleur. *Sources : Ferrari 1984 p. 87 ; Gentil 1923 p. 142-143 ; Théis 1810, s.v. Narcissus.*
- **Nardurus** (genre ; latin et grec) : « queue de Nardus ». - **Nasturtium** (genre ; latin) : le nez tordu. De nasus, nez, et tortus, tordu : la saveur piquante du cresson fait grimacer. Ferrari n'y voit que le nom latin du cresson alénois. *Sources : Ferrari 1984 p. 87 ; Gentil 1923 p. 143.*
- **Nepeta** (genre ; latin, nom de lieu) : la ville de Nepete. Cette cité étrusque (aujourd'hui Nepi, au nord de Rome) aurait donné son nom à la plante ; le nom d'espèce cataria vient du chat, que la cataire attire irrésistiblement. *Sources : Ferrari 1984 p. 87 ; Gentil 1923 p. 144.*

- **Nigella** (genre ; latin) : la petite noire. Diminutif de niger, noir, pour la couleur des graines. *Sources : Ferrari 1984 p. 88 ; Gentil 1923 p. 145 ; Théis 1810, s.v. Nigella.*

- **Nigritella** (genre ; latin) : « petite noire ». Diminutif de niger, pour les fleurs très sombres. Ancien nom (Ferrari 1984) : Nigritella → nom actuel : Gymnadenia (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 88 ; Gentil 1923 p. 145.*

Le mot vient de noscere, connaître : est noble ce qui est connu, célèbre ; **une seule source** (Wiktionary). Gentil y voit, pour une camomille, un hommage à ses vertus médicinales. - **Noccaea** (genre ; nom de personne) : « plante de Nocca ». Dédiée au botaniste italien Domenico Nocca (1758-1841). Nom actuel (GBIF/WCVP 2026) de l'ancien Hutchinsia. **une seule source** (Burkhardt). *Sources : Burkhardt 2018, s.v. Noccaea.*
- **Notholaena** (genre ; grec) : « faux manteau ». - **palustris** (épithète ; latin) : des marais. Tiré de palus, paludis, le marais ; même forme au féminin, neutre palustre, comme l'épipactis des marais, Epipactis palustris. *Sources : Ferrari 1984 p. 169 ; Gentil 1923 p. 76 ; Wiktionary, s.v. palustris et paluster.*

- **Paradisea** (genre ; nom de personne) : dédié au comte Giovanni Paradisi (1760-1826), lettré et mathématicien de Reggio d'Émilie, président du sénat du royaume d'Italie et protecteur de l'auteur du genre. - **Pastinaca** (genre ; latin) : la nourriture. De pastus, nourriture, pour cette racine comestible ; le mot désignait chez les Latins le panais comme la carotte. *Sources : Ferrari 1984 p. 94 ; Gentil 1923 p. 158 ; Théis 1810, s.v. Pastinaca.*

- **Physocaulis** (genre ; grec) : « tige gonflée ». De physa (renflement) et kaulos (tige) : les tiges sont renflées sous les nœuds. Ferrari et Gentil écrivent Physocaulos. - **Portulaca** (genre ; latin) : la petite porte. De portula, petite porte, pour la capsule qui s'ouvre par un couvercle ; Théis juge toutefois l'origine obscure. *Sources : Ferrari 1984 p. 100 ; Gentil 1923 p. 172 ; Théis 1810, s.v. Portulaca.*
- **Potentilla** (genre ; latin) : « petite puissante ». De potens (puissant), pour les grandes vertus médicinales qu'on lui prêtait. Nom actuel (GBIF/WCVP 2026) de l'ancien Duchesnea. *Sources : Ferrari 1984 p. 101 ; Gentil 1923 p. 173 ; Théis 1810, s.v. Potentilla.*
- **pratensis** (épithète ; latin) : des prés. Tiré de pratum, le pré ; même forme au féminin, neutre pratense, comme la sauge des prés, Salvia pratensis. *Sources : Ferrari 1984 p. 174 ; Gentil 1923 p. 191 ; Wiktionary, s.v. pratensis.*
- **Preslia** (genre ; nom de personne) : dédié à Karl Bořivoj Presl (1794-1852), médecin et botaniste de Bohême, professeur à Prague ; Burkhardt associe son frère Jan Svatopluk Presl à l'hommage. Ferrari le dit polonais, Burkhardt bohémien. Ancien nom (Ferrari 1984) : Preslia → nom actuel : Mentha (GBIF/WCVP 2026), soit Mentha cervina. *Sources : Ferrari 1984 p. 101 ; Burkhardt 2018, s.v. Preslia.*
- **Primula** (genre ; latin) : la toute première. Diminutif de primus, premier : la primevère fleurit dès la fin de l'hiver. *Sources : Ferrari 1984 p. 101 ; Gentil 1923 p. 175 ; Théis 1810, s.v. Primula.*
- **Prunella** (genre ; allemand latinisé) : de l'allemand Braune, l'angine, que la brunelle passait pour soigner. Ferrari parle d'une origine probablement germanique ; Gentil précise que Linné a changé la lettre initiale. Ancienne graphie chez Ferrari : Brunella. *Sources : Ferrari 1984 p. 26 ; Gentil 1923 p. 36.*
- **Prunus** (genre ; latin, du grec) : le prunier. Du grec proumnê ; Théis avoue ne pas en connaître l'origine plus lointaine. *Sources : Ferrari 1984 p. 101 ; Gentil 1923 p. 176 ; Théis 1810, s.v. Prunus.*
- **Pseudorlaya** (genre ; grec et nom de personne) : « faux Orlaya ». Du grec pseudês (faux) et d'Orlaya, genre voisin dédié au médecin hongrois János Orlay (1770-1829). Ancien nom (Ferrari 1984) : Pseudorlaya → nom actuel : Daucus (GBIF/WCVP 2026), le genre de la carotte. *Sources : Ferrari 1984 p. 101 ; Gentil 1923 p. 152, s.v. Orlaya ; Burkhardt 2018, s.v. Orlaya.*
- **Psilurus** (genre ; grec) : « queue nue ». De psilos (nu, grêle) et oura (queue) : l'épi, mince et glabre, fait une petite queue. Ancien nom (Ferrari 1984) : Psilurus → nom actuel : Festuca (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 102 ; Gentil 1923 p. 176.*
- **pubescens** (épithète ; latin) : couvert d'un fin duvet. Participe du verbe pubescere, se couvrir de poils, de pubes, le duvet ; c'est la même famille que notre mot puberté (à notre avis). Même forme aux trois genres. *Sources : Ferrari 1984 p. 174 ; Gentil 1923 p. 68 ; Wiktionary, s.v. pubescens.*
- **Punica** (genre ; latin) : la carthaginoise. Les Romains nommaient la grenade malum punicum, la pomme de Carthage, d'où ils la croyaient venue. *Sources : Ferrari 1984 p. 102 ; Théis 1810, s.v. Punica.*
- **purpureus** (épithète ; latin) : pourpre. Tiré de purpura, la pourpre (ou du grec porphyreos) ; formes purpurea et purpureum, comme la scorsonère pourpre, Scorzonera purpurea. *Sources : Ferrari 1984 p. 174 ; Gentil 1923 p. 200 ; Wiktionary, s.v. purpureus.*
- **Pyrus** (genre ; latin) : le poirier. Gentil hésite entre la pyramide (forme du fruit) et un celtique peren, que Théis retient ; Ferrari écrit Pirus et y met aussi le pommier. Malus est aujourd'hui un genre à part (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 98 ; Gentil 1923 p. 165 ; Théis 1810, s.v. Pyrus.*

### Q

- **Quercus** (genre ; latin, peut-être celtique) : le bel arbre. Gentil y voit deux mots celtiques, kaer quez, l'arbre par excellence ; Théis rapproche aussi les druides du nom celtique du chêne. *Sources : Ferrari 1984 p. 103 ; Gentil 1923 p. 177 ; Théis 1810, s.v. Quercus.*

### R

- **Ranunculus** (genre ; latin) : la petite grenouille. Diminutif de rana, grenouille : beaucoup de renoncules aiment, comme elle, les lieux humides. *Sources : Ferrari 1984 p. 103 ; Gentil 1923 p. 178-179 ; Théis 1810, s.v. Ranunculus.*
- **Raphanus** (genre ; grec) : qui paraît vite. De ra, facilement, et phainomai, apparaître : le radis lève en quelques jours. *Sources : Ferrari 1984 p. 103 ; Gentil 1923 p. 180 ; Théis 1810, s.v. Raphanus.*
- **repens** (épithète ; latin) : rampant. Participe du verbe repere, ramper ; même forme aux trois genres. *Sources : Ferrari 1984 p. 176 ; Gentil 1923 p. 180 ; Wiktionary, s.v. repens.*
- **reshni** (épithète ; langue de l'Inde) : d'un nom indien de la mandarine Cléopâtre (à notre avis) ; aucun dictionnaire consulté ne donne ce mot. **une seule source** (à notre avis). Ancien nom : Citrus reshni → nom actuel : Citrus ×aurantium f. aurantium (GBIF/WCVP 2026) ; GBIF le met en synonyme de C. aurantium sans forme. *Sources : GBIF/WCVP 2026.*
- **reticulata** (épithète ; latin) : réticulée, en réseau. De reticulum, petit filet. Blanco (1837) visait le réseau de fibres blanches sous l'écorce de la mandarine. Nom accepté : Citrus reticulata Blanco (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 176 ; Gentil 1923 p. 191 ; Swingle et Reece 1967, ch. 3 ; Wiktionary 2026, s.v. reticulatus ; GBIF/WCVP 2026.*
- **Rhaponticum** (genre ; grec) : la rhubarbe du Pont. De rha, la rhubarbe, et Ponticum, des bords de la mer Noire : la plante a un peu l'allure d'une rhubarbe. Nom actuel (GBIF/WCVP 2026) de l'ancien Leuzea. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 104.*
- **Rheum** (genre ; grec) : la plante du Rha. Le grec rhâ désignait la rhubarbe, et Théis le relie au Rha, ancien nom de la Volga, d'où venait la racine. *Sources : Ferrari 1984 p. 104 ; Théis 1810, s.v. Rheum.*
- **Rhododendron** (genre ; grec) : l'arbre à roses. De rhodon, rose, et dendron, arbre, pour ces arbustes couverts de fleurs roses. *Sources : Ferrari 1984 p. 104 ; Gentil 1923 p. 181 ; Théis 1810, s.v. Rhododendron.*
- **Rhodotypos** (genre ; grec) : « en forme de rose ». De rhodon (rose) et typos (empreinte, figure), pour la fleur qui rappelle une églantine. Ferrari écrit Rhodotypus (orthographe corrigée depuis). **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 104.*
- **Ribes** (genre ; d'origine discutée) : le groseillier. Ferrari et Gentil y voient le danois ribs ; Théis, une plante acide des médecins arabes (une rhubarbe) dont le nom aurait été donné à tort au groseillier. *Sources : Ferrari 1984 p. 104 ; Gentil 1923 p. 182 ; Théis 1810, s.v. Ribes.*
- **Ricinus** (genre ; latin) : la tique. La graine, tachetée et bombée, ressemble à s'y méprendre à une tique gorgée de sang. *Sources : Ferrari 1984 p. 104 ; Théis 1810, s.v. Ricinus.*
- **Rorippa** (genre ; origine inconnue) : étymologie inconnue. Ferrari écrit Roripa (orthographe corrigée depuis : Rorippa). **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 105.*
- **Rosa** (genre ; latin, du grec) : la rose. Proche du grec rhodon ; Théis évoque un celtique rhodd, rouge, Gentil un sanscrit vrad d'après Littré. *Sources : Ferrari 1984 p. 105 ; Gentil 1923 p. 183 ; Théis 1810, s.v. Rosa.*
- **Rosmarinus** (genre ; latin) : « rosée de mer ». De ros (rosée) et marinus (de la mer) pour Gentil et Théis : l'arbuste abonde près des côtes de la Méditerranée ; Ferrari part plutôt de rhus (le sumac) et de marinus ; les Grecs l'appelaient libanôtis, d'après l'encens (Théis). Ancien nom (Ferrari 1984) : Rosmarinus → nom actuel : Salvia (GBIF/WCVP 2026), le romarin est Salvia rosmarinus. *Sources : Ferrari 1984 p. 105 ; Gentil 1923 p. 184 ; Théis 1810, s.v. Rosmarinus.*
- **rotundifolius** (épithète ; latin) : à feuilles rondes. Assemblage de rotundus (rond) et folium (feuille) ; formes rotundifolia et rotundifolium. *Sources : Ferrari 1984 p. 177 ; Gentil 1923 p. 95 ; Wiktionary, s.v. rotundifolius.*
- **ruber** (épithète ; latin) : rouge. Formes rubra et rubrum ; même racine que le grec erythros, rouge. *Sources : Ferrari 1984 p. 177 ; Gentil 1923 p. 91 ; Wiktionary, s.v. ruber.*
- **Rubus** (genre ; latin) : le rouge. De ruber, rouge, couleur des fruits de nombreuses ronces et framboisiers. *Sources : Ferrari 1984 p. 105 ; Gentil 1923 p. 184.*
- **Rumex** (genre ; latin) : le javelot. Rumex désignait chez les Latins une sorte de pique, dont les feuilles de l'oseille ont la forme en fer de lance ; Ferrari ne donne que le nom latin. *Sources : Ferrari 1984 p. 105 ; Gentil 1923 p. 186 ; Théis 1810, s.v. Rumex.*
- **Ruta** (genre ; grec ou latin) : la rue. Ferrari n'y voit que l'appellation latine de la rue ; Gentil le tire de rhuô, préserver, parce qu'on la tenait pour un remède ; Théis note que le nom est à peu près le même dans toutes les langues. *Sources : Ferrari 1984 p. 106 ; Gentil 1923 p. 188 ; Théis 1810, s.v. Ruta.*

### S

- **Salicornia** (genre ; latin) : « sel ». Théis le rattache à salicor, nom languedocien latinisé par Tournefort, lui-même tiré de sal (le sel) : on en tirait de la soude. Nom actuel (GBIF/WCVP 2026) de l'ancien Arthrocnemum. *Sources : Gentil 1923 p. 189 ; Théis 1810, s.v. Salicornia.*
- **Salix** (genre ; latin, peut-être celtique) : le saule. Gentil propose un celtique sal-lis, près de l'eau, là où pousse le saule ; Ferrari ne donne que le nom latin ; **une seule source** (pour ce sens). *Sources : Ferrari 1984 p. 106 ; Gentil 1923 p. 189.*
- **Salvia** (genre ; latin) : celle qui sauve. De salvare, guérir : l'école de Salerne demandait comment pourrait mourir un homme qui a de la sauge dans son jardin. Ancien nom (Ferrari 1984) : Rosmarinus (voir Rosmarinus) → nom actuel : Salvia rosmarinus (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 106 et p. 105 ; Gentil 1923 p. 191 et p. 184 ; Théis 1810, s.v. Salvia.*
- **Sambucus** (genre ; grec) : l'instrument de musique. La sambukê était un instrument que l'on fabriquait, dit-on, avec le bois du sureau. *Sources : Ferrari 1984 p. 107 ; Gentil 1923 p. 192 ; Théis 1810, s.v. Sambucus.*
- **sarcodactylis** (épithète ; grec) : aux doigts de chair. De sarx, chair, et daktylos, doigt (à notre avis) : la main de Bouddha, cédrat dont le fruit se divise en doigts. Swingle et Reece en font une variété du cédratier, cultivée en Chine et au Japon, dont le fruit fendu en doigts a peu ou pas de pulpe. Ancien nom : Citrus medica var. sarcodactylis → nom actuel : Citrus ×limon (WCVP 2026), rattachement surprenant pour un cédrat ; GBIF le range, lui, sous C. medica. **une seule source** (à notre avis, pour l'étymologie). *Sources : Swingle et Reece 1967, ch. 3 ; GBIF/WCVP 2026.*
- **Sarothamnus** (genre ; grec) : « buisson à balais ». De saros (balai) et thamnos (arbuste) : on en liait des balais, d'où « genêt à balais ». Ancien nom (Ferrari 1984) : Sarothamnus → nom actuel : Cytisus (GBIF/WCVP 2026), soit Cytisus scoparius. *Sources : Ferrari 1984 p. 107 ; Gentil 1923 p. 193.*
- **sativus** (épithète ; latin) : cultivé, semé par l'homme. Formé sur satus, participe du verbe serere, semer ; formes sativa et sativum, comme le panais, Pastinaca sativa. *Sources : Ferrari 1984 p. 178 ; Gentil 1923 p. 158 ; Wiktionary, s.v. sativus.*
- **Satureja** (genre ; latin) : la sarriette. Ancien nom (Ferrari 1984) : Satureia, la graphie de Ferrari et de Gentil, qui partent du latin satureia ; Gentil le relie à satura, un plat de viandes mêlées qu'elle parfumait, quand Linné, cité par Théis, y voyait les satyres et une plante aphrodisiaque. *Sources : Ferrari 1984 p. 107 ; Gentil 1923 p. 193 ; Théis 1810, s.v. Satureja.*
- **scandens** (épithète ; latin) : grimpant. Participe du verbe scandere, monter, grimper ; même forme aux trois genres. *Sources : Ferrari 1984 p. 178 ; Wiktionary, s.v. scandens.*
- **Scilla** (genre ; grec) : nom grec de la scille. Les Grecs appelaient déjà skilla la scille maritime. Nom actuel (GBIF/WCVP 2026) de l'ancien Adenoscilla. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 108.*
- **Scleropoa** (genre ; grec) : « herbe dure ». De skleros (dur, raide) et poa (herbe). Ancien nom (Ferrari 1984) : Scleropoa → nom actuel : Catapodium (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 108 ; Gentil 1923 p. 198.*
- **Scolopendrium** (genre ; grec) : « scolopendre ». Les longues lignes de sores sous la fronde évoquent les pattes d'un mille-pattes. Ancien nom (Ferrari 1984) : Scolopendrium → nom actuel : Asplenium (GBIF/WCVP 2026), la scolopendre est Asplenium scolopendrium. *Sources : Ferrari 1984 p. 109 ; Gentil 1923 p. 198 ; Wiktionary, s.v. Scolopendrium.*
- **Sechium** (genre ; origine inconnue) : le genre de la chayotte, d'étymologie inconnue. Ancien nom (Ferrari 1984) : Sechium → nom actuel : Sicyos (GBIF/WCVP 2026), la chayotte est Sicyos edulis. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 109.*
- **Securigera** (genre ; latin) : « porte-hache ». De securis (hache) et gerere (porter), pour la gousse en forme de lame. Ancien nom (Ferrari 1984) : Securigera → nom actuel : Coronilla (GBIF/WCVP 2026), soit Coronilla varia. *Sources : Ferrari 1984 p. 109 ; Gentil 1923 p. 200 ; Wiktionary, s.v. Securigera.*
- **Sedum** (genre ; latin) : celle qui s'assoit. Théis et Gentil y voient sedere, être assis, pour ces plantes posées sur les murs et les pierres ; Ferrari préfère sedare, apaiser. *Sources : Ferrari 1984 p. 109 ; Gentil 1923 p. 201 ; Théis 1810, s.v. Sedum.*
- **sempervirens** (épithète ; latin) : toujours vert, au feuillage persistant. Assemblage de semper (toujours) et virens (verdoyant) ; même forme aux trois genres. *Sources : Ferrari 1984 p. 179 ; Gentil 1923 p. 109 ; Wiktionary, s.v. sempervirens.*
- **Sempervivum** (genre ; latin) : toujours vivant. De semper, toujours, et vivus, vivant : la joubarbe survit au sec et au froid. *Sources : Ferrari 1984 p. 110 ; Gentil 1923 p. 203 ; Théis 1810, s.v. Sempervivum.*
- **Sesamoides** (genre ; grec) : « qui ressemble au sésame ». Nom de Sesamum suivi du suffixe -oides (semblable à). Nom actuel (GBIF/WCVP 2026) de l'ancien Astrocarpus. **une seule source** (Gentil). *Sources : Gentil 1923 p. 27.*
- **Severinia** (genre ; latin moderne) : en l'honneur de Marco Aurelio Severino (1580-1656), anatomiste de Naples, mort de la peste. Tenore a créé le genre en 1840. **une seule source** (Burkhardt). Ancien nom : Severinia buxifolia → nom actuel : Atalantia buxifolia (GBIF/WCVP 2026), Atalantia rappelant Atalante, la chasseresse de la mythologie grecque ; GBIF ne trouve pas Severinia. *Sources : Burkhardt 2018, s.v. Severinia et Atalantia ; GBIF/WCVP 2026.*
- **Sicyos** (genre ; grec) : « concombre ». Un des noms grecs du concombre, sikyos ; la plante en a le feuillage et les fruits. Nom actuel (GBIF/WCVP 2026) de l'ancien Sechium : la chayotte est Sicyos edulis. *Sources : Ferrari 1984 p. 111 ; Théis 1810, s.v. Sicyos ; Wiktionary, s.v. Sicyos.*
- **Silene** (genre ; grec) : origine discutée. Ferrari la dit inconnue ; Théis y voit Silène, compagnon ivre de Bacchus couvert de bave, car plusieurs espèces sont collantes. Nom actuel (GBIF/WCVP 2026) des anciens Cucubalus et Lychnis. *Sources : Ferrari 1984 p. 111 ; Théis 1810, s.v. Silene.*
- **Simethis** (genre ; mythologie) : nom de la nymphe Symaethis, liée au fleuve sicilien Symaethus et mère d'Acis dans la fable ; Gentil propose aussi un mot grec pour la courbure des feuilles. Ferrari écrit Symaethis (orthographe corrigée depuis). *Sources : Ferrari 1984 p. 111 ; Gentil 1923 p. 209.*
- **sinensis** (épithète ; latin moderne) : de Chine. Formé sur Sina, la Chine, au même sens que chinensis. C'est l'orange douce. Ancien nom : Citrus sinensis (L.) Osbeck → nom actuel : Citrus ×aurantium f. aurantium (GBIF/WCVP 2026) ; GBIF le met en synonyme de C. aurantium sous l'auteur (Mill.) Pers. 1806. Le nom reste très employé en horticulture. *Sources : Ferrari 1984 p. 140, s.v. Chinensis ; Wiktionary 2026, s.v. sinensis ; GBIF/WCVP 2026.*
- **Solanum** (genre ; latin) : celle qui calme. Gentil et Théis le tirent de solari, soulager, pour les propriétés calmantes de certaines espèces ; Ferrari y voit sol, le soleil. Ancien nom : Lycopersicon, pêche de loup (lykos + persikon), pour la tomate → nom actuel : Solanum lycopersicum (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 112 ; Gentil 1923 p. 211 ; Théis 1810, s.v. Solanum.*
- **Sorbus** (genre ; latin) : le sorbier. Gentil le rattache à sorbere, absorber ou resserrer, pour les fruits astringents ; Ferrari ne donne que le nom latin ; **une seule source** (pour ce sens). *Sources : Ferrari 1984 p. 113 ; Gentil 1923 p. 212.*
- **Sorghum** (genre ; italien) : Ferrari dit l'étymologie inconnue ; le Wiktionary tire le mot de l'italien sorgo, issu d'un latin populaire « (herbe) de Syrie ». Ferrari écrit Sorgum (orthographe corrigée depuis : Sorghum, à ne pas confondre avec un homonyme Sorgum Adanson rangé dans Holcus). **une seule source** (Wiktionary). *Sources : Ferrari 1984 p. 113 ; Wiktionary, s.v. sorghum.*
- **Spartina** (genre ; latin) : du latin spartum, la fibre de sparte dont on tressait des cordes, lui-même du grec sparton (corde). Ancien nom (Ferrari 1984) : Spartina → nom actuel : Sporobolus (GBIF/WCVP 2026), ex. Sporobolus maritimus. **une seule source** (pour le lien avec spartum). *Sources : Ferrari 1984 p. 113 ; Wiktionnaire, s.v. spartum.*
- **speciosus** (épithète ; latin) : beau, qui a belle apparence. Tiré de species, l'aspect ; formes speciosa et speciosum. *Sources : Ferrari 1984 p. 180 ; Gentil 1923 p. 154 ; Wiktionary, s.v. speciosus.*
- **Spergula** (genre ; latin) : « qui répand ». De spargere (répandre) : la plante sème ses graines au loin. Nom actuel (GBIF/WCVP 2026) de l'ancien Delia. *Sources : Ferrari 1984 p. 113 ; Théis 1810, s.v. Spergula.*
- **Spinacia** (genre ; d'origine discutée) : l'épinard. Ferrari le tire de l'arabe isfinag, la plante étant venue d'Orient ; Théis y voit spina, épine, pour ses graines piquantes. *Sources : Ferrari 1984 p. 114 ; Théis 1810, s.v. Spinacia.*
- **spinosus** (épithète ; latin) : épineux. Tiré de spina, l'épine ; formes spinosa et spinosum, comme le prunellier, Prunus spinosa. *Sources : Ferrari 1984 p. 180 ; Gentil 1923 p. 176 ; Wiktionary, s.v. spinosus.*
- **splendens** (épithète ; latin) : brillant, éclatant. Participe du verbe splendere, briller ; même forme aux trois genres. *Sources : Ferrari 1984 p. 180 ; Gentil 1923 p. 116 ; Wiktionary, s.v. splendens.*
- **Sporobolus** (genre ; grec) : « qui lance ses graines ». De spora (semence) et bolos (jet) : les graines sont expulsées à maturité. Nom actuel (GBIF/WCVP 2026) de l'ancien Spartina. *Sources : Ferrari 1984 p. 114 ; Gentil 1923 p. 214.*
- **Stellaria** (genre ; latin) : « étoilée ». De stella (étoile), pour les petites fleurs blanches en étoile. Nom actuel (GBIF/WCVP 2026) de l'ancien Malachium (ou Myosoton) : Stellaria aquatica. *Sources : Ferrari 1984 p. 114 ; Gentil 1923 p. 215 ; Théis 1810, s.v. Stellaria.*
- **Stevia** (genre ; nom de personne, espagnol) : en l'honneur de Pedro Jaime Esteve. Cavanilles a dédié le genre à ce médecin de Valencia du XVIe siècle, latinisé en Stevius. *Sources : Théis 1810, s.v. Stevia ; Burkhardt 2018, s.v. Stevia.*
- **Succowia** (genre ; nom de personne) : dédié à Georg Adolph Suckow (1751-1813), botaniste allemand. Ferrari écrit Suckowia (orthographe corrigée depuis). *Sources : Ferrari 1984 p. 115 ; Burkhardt 2018, s.v. Succowia.*
- **sudachi** (épithète ; japonais) : du japonais sudachi, écrit avec les caractères du vinaigre et du tachibana (à notre avis pour le sens des caractères). **une seule source** (Wiktionary). Ancien nom : Citrus sudachi → nom actuel : Citrus ×junos (GBIF/WCVP 2026) ; GBIF ne trouve que le genre. *Sources : Wiktionary 2026, s.v. sudachi ; GBIF/WCVP 2026.*
- **sunki** (épithète ; chinois) : d'un nom chinois de la mandarine Sunki (à notre avis) ; aucun dictionnaire consulté ne donne ce mot. **une seule source** (à notre avis). Ancien nom : Citrus sunki → nom actuel : Citrus ×depressa (GBIF/WCVP 2026) ; GBIF le met sous C. tachibana. *Sources : GBIF/WCVP 2026.*
- **sylvestris** (épithète ; latin) : des forêts, et par extension sauvage, non cultivé. Tiré de silva, la forêt ; le latin classique écrit silvestris, les botanistes souvent sylvestris. Même forme au féminin, neutre sylvestre. *Sources : Ferrari 1984 p. 179 ; Gentil 1923 p. 144 ; Wiktionary, s.v. silvestris et sylvestris.*
- **Syringa** (genre ; grec) : la flûte. De syrinx, le tuyau ou la flûte de Pan : les rameaux à moelle tendre se vidaient facilement pour faire des tubes ; Théis rappelle la nymphe Syrinx changée en roseau. *Sources : Ferrari 1984 p. 116 ; Théis 1810, s.v. Syringa.*

### T

- **tachibana** (épithète ; japonais) : nom japonais d'un petit agrume sauvage, emblème ancien du Japon (à notre avis pour l'emblème, non sourcé ici). **une seule source** (Wiktionary). - **taitensis** (épithète ; latin moderne) : de Tahiti (à notre avis), à l'époque où l'on écrivait Otahiti. Risso l'a publié en 1844. **une seule source** (à notre avis). Nom accepté : Citrus ×taitensis Risso (GBIF/WCVP 2026), qui absorbe C. jambhiri. *Sources : GBIF/WCVP 2026.*
- **Tamus** (genre ; latin) : nom latin d'une plante qu'on n'a pas su identifier, cité par Pline et Columelle. Ancien nom (Ferrari 1984) : Tamus → nom actuel : Dioscorea (GBIF/WCVP 2026), le tamier est Dioscorea communis. *Sources : Ferrari 1984 p. 116 ; Gentil 1923 p. 219.*
- **tangor** (nom d'hybride ; anglais) : tangerine + orange. Nom de groupe pour les hybrides de mandarine et d'orange douce ; tangelo est fait de la même façon, avec pomelo (*C. ×paradisi*). *Sources : Wiktionnaire 2026, s.v. tangor ; Wiktionary 2026, s.v. tangor et tangelo.*
- **Taraxacum** (genre ; arabe) : le pissenlit. Du nom arabe tarakhshaqûn ; Gentil cite aussi des hypothèses grecques (taraxis, trouble, et akos, remède). *Sources : Ferrari 1984 p. 116 ; Gentil 1923 p. 219.*
- **Taxus** (genre ; latin, d'origine discutée) : l'if. Trois lectures : Ferrari remonte à une racine indo-européenne du travail habile, Gentil à taxis, rangée, Théis à toxon, l'arc, et toxikon, le poison, deux usages bien réels du bois et de la plante. *Sources : Ferrari 1984 p. 117 ; Gentil 1923 p. 219 ; Théis 1810, s.v. Taxus.*
- **Tetragonolobus** (genre ; grec) : « gousse à quatre angles ». De tetragônos (à quatre angles) et lobos (gousse) : la gousse porte quatre ailes. Ancien nom (Ferrari 1984) : Tetragonolobus → nom actuel : Lotus (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 117 ; Gentil 1923 p. 220.*
- **Thymus** (genre ; grec, d'origine discutée) : le thym. Gentil y voit thuô, parfumer ou brûler en offrande, Théis thymos, le courage, et Ferrari un mot égyptien lié à l'embaumement. *Sources : Ferrari 1984 p. 118 ; Gentil 1923 p. 222 ; Théis 1810, s.v. Thymus.*
- **Tilia** (genre ; latin) : le tilleul. Gentil propose le grec ptilon, aile, pour la bractée qui emporte les fruits au vent ; Ferrari ne donne que le nom latin ; **une seule source** (pour ce sens). *Sources : Ferrari 1984 p. 118 ; Gentil 1923 p. 223.*
- **Tillaea** (genre ; nom de personne) : dédié à Michelangelo Tilli, mort en 1740, médecin et professeur de botanique à Pise, auteur du catalogue du jardin médicinal de Pise (la date de naissance varie selon les sources). Ancien nom (Ferrari 1984) : Tillaea → nom actuel : Crassula (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 118 ; Gentil 1923 p. 222 ; Théis 1810, s.v. Tillaea ; Burkhardt 2018, s.v. Tillaea.*
- **tinctorius** (épithète ; latin) : des teinturiers, qui sert à teindre. Tiré du verbe tingere, teindre ; formes tinctoria et tinctorium, comme le genêt des teinturiers, Genista tinctoria, qui donnait une teinture jaune. *Sources : Ferrari 1984 p. 183 ; Gentil 1923 p. 93 ; Wiktionary, s.v. tinctorius.*
- **tomentosus** (épithète ; latin) : tomenteux, couvert d'un feutre de poils. Tiré de tomentum, la bourre, le duvet ; formes tomentosa et tomentosum. *Sources : Ferrari 1984 p. 183 ; Gentil 1923 p. 89 ; Wiktionary, s.v. tomentosus.*
- **Toxylon** (genre ; grec) : « bois d'arc ». De toxon (arc) et xylon (bois), d'où le nom commun de bois d'arc. Ancien nom (Ferrari 1984) : Toxylon → nom actuel : Maclura (GBIF/WCVP 2026), l'oranger des Osages est Maclura pomifera. **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 119.*
- **Trientalis** (genre ; latin) : de triens, « un tiers ». Pour Ferrari et Théis, la plante ne dépasse guère le tiers d'un pied romain ; Gentil pense plutôt à la pièce romaine du même nom, pour l'aspect de sa corolle. Ancien nom (Ferrari 1984) : Trientalis → nom actuel : Lysimachia (GBIF/WCVP 2026), soit Lysimachia europaea. *Sources : Ferrari 1984 p. 120 ; Théis 1810, s.v. Trientalis ; Gentil 1923 p. 225.*
- **trifoliata** (épithète ; latin) : à trois folioles. De tres, trois, et folium, feuille : la feuille de l'oranger trifolié est faite de trois folioles. Linné l'avait mis dans Citrus en 1763, Rafinesque l'en a sorti en 1838, et le voici revenu. **une seule source** (Ferrari). Nom actuel : Citrus trifoliata L. (GBIF/WCVP 2026) ; ancien nom : Poncirus trifoliata, synonyme dans les deux bases. *Sources : Ferrari 1984 p. 183 ; GBIF/WCVP 2026.*
- **Tropaeolum** (genre ; grec) : le petit trophée. On voit dans la feuille ronde un bouclier et dans la fleur un casque, comme sur les trophées antiques ; le nom de capucine vient de l'éperon en capuchon. *Sources : Ferrari 1984 p. 121 ; Théis 1810, s.v. Tropaeolum.*
- **tuberosus** (épithète ; latin) : tubéreux, à renflements. Tiré de tuber, la bosse, le renflement ; formes tuberosa et tuberosum. *Sources : Ferrari 1984 p. 184 ; Gentil 1923 p. 221 ; Wiktionary, s.v. tuberosus.*
- **Tulipa** (genre ; persan, par le turc) : le turban. Du mot dulband, turban, pour la forme de la fleur. *Sources : Ferrari 1984 p. 121 ; Gentil 1923 p. 229 ; Théis 1810, s.v. Tulipa.*

### U

- **Ulmus** (genre ; latin, d'origine celtique) : l'orme. Le nom latin se rapproche d'un celtique elm, qu'on retrouve dans l'anglais elm. *Sources : Ferrari 1984 p. 122 ; Gentil 1923 p. 231 ; Théis 1810, s.v. Ulmus.*
- **unshiu** (épithète ; japonais) : sans doute la lecture japonaise de Wenzhou, ville chinoise du Zhejiang (à notre avis). Swingle et Reece font naître le satsuma au Japon d'un semis de hasard d'une orange de Huangyan, dans cette même province ; le nom satsuma est celui d'une province de Kyūshū. **une seule source** (à notre avis). Ancien nom : Citrus unshiu Marcow. → nom actuel : Citrus ×aurantium f. deliciosa (GBIF/WCVP 2026) ; GBIF ne trouve que le genre. *Sources : Swingle et Reece 1967, ch. 3 ; Wiktionnaire 2026, s.v. satsuma ; GBIF/WCVP 2026.*
- **Urginea** (genre ; nom de lieu) : d'après la tribu des Beni Urgin, en Algérie, où la plante a été cueillie. Ancien nom (Ferrari 1984) : Urginea → nom actuel : Drimia (GBIF/WCVP 2026), la scille maritime est Drimia maritima. *Sources : Ferrari 1984 p. 122 ; Wiktionary, s.v. Urginea.*
- **Urtica** (genre ; latin) : celle qui brûle. De urere, brûler : toute personne qui a frôlé une ortie comprend. *Sources : Ferrari 1984 p. 122 ; Gentil 1923 p. 232 ; Théis 1810, s.v. Urtica.*

### V

- **Vaccinium** (genre ; latin) : la myrtille. Nom latin d'une plante mal identifiée ; Gentil hésite entre vacca, vache, et bacca, baie. *Sources : Ferrari 1984 p. 122 ; Gentil 1923 p. 232 ; Théis 1810, s.v. Vaccinium.*
- **Valantia** (genre ; nom de personne) : dédié à Sébastien Vaillant (1669-1722), professeur de botanique au Jardin du roi à Paris. Ferrari écrit Vaillantia (orthographe corrigée depuis : Valantia, graphie de Linné). *Sources : Ferrari 1984 p. 122 ; Burkhardt 2018, s.v. Valantia.*
- **Valeriana** (genre ; latin) : se bien porter. De valere, être en bonne santé, pour ses vertus apaisantes ; Théis signale l'idée de Linné d'un roi Valère. *Sources : Ferrari 1984 p. 122 ; Gentil 1923 p. 233 ; Théis 1810, s.v. Valeriana.*
- **variegatus** (épithète ; latin) : panaché, bigarré. Participe du verbe variegare, rendre varié ; formes variegata et variegatum. *Sources : Ferrari 1984 p. 185 ; Gentil 1923 p. 148 ; Wiktionary, s.v. variegatus.*
- **Velezia** (genre ; nom de personne) : dédié au botaniste espagnol Cristóbal Vélez, apothicaire à Madrid, mort en 1753 (sa date de naissance varie selon les sources). Ancien nom (Ferrari 1984) : Velezia → nom actuel : Dianthus (GBIF/WCVP 2026), soit Dianthus nudiflorus. *Sources : Ferrari 1984 p. 123 ; Gentil 1923 p. 232 ; Burkhardt 2018, s.v. Velezia.*
- **Verbena** (genre ; latin, peut-être celtique) : la verveine. Gentil et Théis le tirent d'un celtique ferfaen, la plante sacrée des druides ; Ferrari juge l'origine incertaine. *Sources : Ferrari 1984 p. 123 ; Gentil 1923 p. 235 ; Théis 1810, s.v. Verbena.*
- **Vesicaria** (genre ; latin) : « vessie ». De vesica, pour le fruit renflé comme une petite outre. Ancien nom (Ferrari 1984) : Vesicaria → nom actuel : Alyssoides (GBIF/WCVP 2026), la vésicaire est Alyssoides utriculata. *Sources : Ferrari 1984 p. 123 ; Gentil 1923 p. 236.*
- **Vibo** (genre ; latin) : nom latin d'une plante réputée contre le scorbut. Ancien nom (Ferrari 1984) : Vibo → nom actuel : Rumex (GBIF/WCVP 2026). **une seule source** (Ferrari). *Sources : Ferrari 1984 p. 123.*
- **Viburnum** (genre ; latin) : celle qui lie. De viere, tresser, pour les rameaux souples qui servaient de liens. *Sources : Ferrari 1984 p. 124 ; Gentil 1923 p. 236 ; Théis 1810, s.v. Viburnum.*
- **Vicia** (genre ; latin) : la vesce. Gentil y voit vincire, lier, pour les vrilles qui s'accrochent ; Théis préfère un celtique gwig. *Sources : Ferrari 1984 p. 124 ; Gentil 1923 p. 236 ; Théis 1810, s.v. Vicia.*
- **Vinca** (genre ; latin) : la pervenche. De vincire, lier, pour les tiges souples, ou de vincere, vaincre, car elle reste verte tout l'hiver ; Théis tient l'origine pour incertaine. *Sources : Ferrari 1984 p. 124 ; Gentil 1923 p. 238 ; Théis 1810, s.v. Vinca.*
- **Viola** (genre ; latin, du grec) : la violette. Proche du grec ion ; la légende dit que Zeus fit pousser ces fleurs pour nourrir Io, changée en génisse. *Sources : Ferrari 1984 p. 124 ; Gentil 1923 p. 238 ; Théis 1810, s.v. Viola.*
- **Viscum** (genre ; latin) : la glu. Les baies collantes du gui servaient à faire la glu ; Théis rattache aussi le mot gaulois qui a donné « gui ». *Sources : Ferrari 1984 p. 124 ; Gentil 1923 p. 239 ; Théis 1810, s.v. Viscum.*
- **Vitis** (genre ; latin) : la vigne. Gentil le tire de viere, lier, pour les vrilles ; Théis d'un celtique gwid ; Ferrari ne donne que le nom latin. *Sources : Ferrari 1984 p. 124 ; Gentil 1923 p. 239 ; Théis 1810, s.v. Vitis.*
- **volkameriana** (épithète ; latin moderne) : de Volkamer (à notre avis). Johann Christoph Volkamer (1644-1720), publia en 1708 les Hespérides de Nuremberg, grand livre illustré d'agrumes, avec l'aide de son frère Johann Georg. Ancien nom : Citrus volkameriana Ten. et Pasq. → nom actuel : Citrus ×limon (GBIF/WCVP 2026), même rattachement chez GBIF. *Sources : Théis 1810, s.v. Volkameria ; Burkhardt 2018, s.v. Volkameria ; GBIF/WCVP 2026.*
- **vulgaris** (épithète ; latin) : commun, ordinaire, bien connu. Tiré de vulgus, la foule, le peuple ; même forme au féminin, neutre vulgare. *Sources : Ferrari 1984 p. 186 ; Gentil 1923 p. 11 ; Wiktionary, s.v. vulgaris.*
- **Vulpia** (genre ; nom de personne) : dédié à Johann Samuel Vulpius (1760-1846), pharmacien à Pforzheim qui étudiait la flore du Bade ; Gentil y voit plutôt vulpes (le renard), pour l'épi en queue de renard. Ancien nom (Ferrari 1984) : Vulpia → nom actuel : Festuca (GBIF/WCVP 2026). *Sources : Ferrari 1984 p. 124 ; Burkhardt 2018, s.v. Vulpia ; Gentil 1923 p. 240.*

### W

- **Wisteria** (genre ; nom de personne, américain) : en l'honneur de Caspar Wistar. Nuttall a dédié la glycine à ce médecin et anatomiste de Philadelphie (1761-1818). Deux graphies circulent : Wisteria, la plus courante aujourd'hui, et Wistaria, celle de Ferrari et de Burkhardt. *Sources : Ferrari 1984 p. 125 ; Burkhardt 2018, s.v. Wistaria.*

### Y

- **Yucca** (genre ; arawak, langue des Antilles) : un nom indigène. Nom employé par les habitants d'Haïti, repris par les botanistes. *Sources : Ferrari 1984 p. 126 ; Théis 1810, s.v. Yucca.*

### Z

- **Zanthoxylum** (genre ; grec) : « bois jaune ». De xanthos (jaune) et xylon (bois) ; Théis cite l'espèce dont le tronc hérissé de bosses épineuses rappelle la massue d'Hercule. Ferrari écrit Xanthoxylum (orthographe corrigée depuis). *Sources : Ferrari 1984 p. 125 ; Théis 1810, s.v. Zanthoxylum ; Wiktionary, s.v. Zanthoxylum.*
- **Zea** (genre ; grec) : l'épeautre. Les Grecs nommaient ainsi une céréale, rattachée par Théis à zaô, vivre ; le mot maïs, lui, vient d'une langue d'Amérique. *Sources : Ferrari 1984 p. 126 ; Théis 1810, s.v. Zea.*
- **Zingiber** (genre ; arabe, peut-être d'origine indienne) : le gingembre. De l'arabe zenjebil, passé par le grec et le latin ; Théis rapporte qu'on y voyait le nom d'une région de l'Inde du Sud où la plante pousse seule. **une seule source** (Théis). *Sources : Théis 1810, s.v. Amomum.*
